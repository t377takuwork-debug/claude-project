# note値付けの基準

## 基本レンジ
- 初めて出す記事: 480〜980円。買うハードルを下げて実績とレビューを作る段階
- 2本目以降の通常記事: 980〜1,980円
- 体系的なノウハウ・分量が厚いもの: 1,980〜2,980円

## 決め方
1. リサーチ結果の「類似テーマの価格帯」を最優先の根拠にする。売れ筋の帯から大きく外さない
2. 帯の中でどこに置くかは中身で決める: 体験の希少性が高い/再現手順まで書く → 帯の上限側。体験談中心で手順が薄い → 帯の下限側
3. 迷ったら安い方。高くて売れないより、安くて実績が付く方が次に繋がる

## 禁止
- 根拠なく高額(5,000円以上)を付けない
- 「本当は◯万円の価値」のような煽り文句を価格の根拠にしない
