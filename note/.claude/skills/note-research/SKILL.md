# noteリサーチの判断基準

## 調べる4点
1. **価格帯**: 類似テーマの有料記事がいくらで売られているか。売れ筋の帯を把握する
2. **スキ数の傾向**: 上位記事のスキ数。スキが付いている=読まれて反応がある証拠
3. **タイトルの型**: 売れている記事のタイトルに共通する型(数字・体験・断言など)
4. **競合の厚さ**: 同テーマの記事数。多すぎる=埋もれる、ゼロ=需要がない可能性

## 有望と判断する条件
- 類似テーマに有料記事が存在し、スキが付いているものがある(=お金を払う人がいる市場)
- その中で「体験ベース」の切り口がまだ厚くない
- ユーザーのヒアリング内容に、その市場に出せる固有の体験がある

## 避けるテーマ
- 有料記事がほぼ存在しないテーマ(需要が確認できない)
- 専門資格や実績が前提になるテーマで、ユーザーにそれがない場合
- ユーザーの体験と接点がない、ただ流行っているだけのテーマ

## 注意
- noteの購入数は非公開。「何部売れた」は取得できないので推測で書かない。判断材料は価格・スキ・記事数・タイトル傾向まで
