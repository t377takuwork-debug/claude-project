# 売れるnote記事の型

## 大原則
売れるnoteは、プロの完璧な教科書ではなく「半歩先を歩いた人の生々しい話」。
読者と同じ場所から始めて、少し先に行った人の失敗と学びに、人はお金を払う。

## 構成の型
1. **冒頭(無料)**: 読者の痛みを読者の言葉で書く → 自分も同じだったと明かす → この記事で何が分かるかを約束する
2. **体験(無料〜有料の境目)**: 何に失敗し、何を間違えていたか。生々しく具体的に。ここが記事の心臓
3. **転換(有料)**: 何に気づいて、何を変えたか
4. **手順(有料)**: 読者が同じことをやるための具体的なステップ
5. **締め(有料)**: 最初の一歩を1つだけ指定する

## 有料ラインの位置
- 体験の「一番読みたくなる瞬間」の直前に引く。失敗の全貌と原因が分かる手前
- 無料部分だけで「この人は自分と同じ場所にいた」が伝わる分量を確保する

## 本人の体験の扱い
- ユーザーから聞いた体験は、要約せずディテールを残す(金額・期間・そのとき思ったこと)
- 体験はヒアリング記録にあるものだけを使う。記録にない場面・数字を創作して本人の体験として書かない。記録が薄い場合は薄いなりの粒度で書き、読者への約束を膨らませない
- 空欄・プレースホルダー・「後で埋める」箇所を残さない。記録にない数字が要る箇所は、数字を使わない書き方に変える。完成稿はそのまま売れる状態にする

## AIっぽさの消し方(編集AIのチェック項目)
- 誰にでも当てはまる一般論の段落 → 削るか本人の具体に差し替える
- 同じ語尾の3連続以上 → 崩す
- 「絶対」「必ず」「誰でも」の安易な断定 → 本人の体験の範囲の言い方に直す
- 箇条書きだらけ → 心臓部は文章で語る
- 本人の固有名詞・数字・失敗が1画面に1つも出てこない状態を作らない
