# X投稿の決まり（s4lv / @cfrms4lv）

**声と書き方は `rules/s4lv_voice.md`、材料と事実は `rules/sns_common_rules.md`。** このファイルは、Xだけの決まりを書く。広め方の仕組みの資料は `brands/reference/x_algorithm_2026.md`。

## 反響の狙い（書く前に決める）

投稿ごとに、次のどちらを狙うかを1つ決めてから書く。1つの投稿に両方を混ぜない。比率の目安は A6：B4。

| 狙い | どんな投稿か |
|---|---|
| A 会話・引用型 | フォローしていない人が見ても、返信・引用したくなる投稿。反論できる断言、予測、抜けている事実の指摘など、返したくなる隙を作る |
| B 一次情報・共有型 | これだけ見せれば伝わる、人に送りたくなる完結した投稿。「保存してください」とは言わず、中身が完結していることで閉じる |

- 狙うのは「いまのフォロワーとの会話」ではなく、「フォローしていない人が返信・引用・共有したくなること」
- 煽り・挑発にはしない（通報・ミュートなどの悪い反応は、良い反応より重く数えられる）
- s4lvの規模で外に届きやすいのは、「1行目で何の話か分かる・番号の手順・具体的な名前・短い」投稿
- リポストのお願いや、キャンペーン型の投稿はしない

## 1行目と長さ

- 1行目は1行に収める（2行にまたがると、途中で切られやすい）
- 見つけてもらうための投稿は、「さらに表示」に頼らず1画面で完結させる（結論 → 数字か手順 → 次の一手）。長い保存用の投稿（チェックリストなど）は週1〜2本まで
- 字数の決まった上限はない。ただし原則は短く。長くするのは、中身が何段かの判断・手順を必要とするときだけ
- 削りすぎない。余裕があるのに、話し言葉のニュアンスまで削らない
- 本文にURLとハッシュタグを入れない

## Note記事への誘導の回

- 週1本を目安に、型・思想の投稿のうち1本を誘導の回にする。1日に2本以上は入れない
- ネタ元は `articles/note_article_index.md` の章。「直近X誘導日」が空欄か、いちばん古い記事を選ぶ。使ったら、その欄に日付を書く
- 本文は、章の考え方を見せるだけにする。売り込みの一文は入れない。有料記事は、考え方を見せるところまで（キーワードの選び方の決まりや、記事構成の型を、そのまま文章で渡さない）
- URLは本文に入れず、自己リプライに、そのままコピペできる形で書く。自己リプライには「読む理由」（何が分かるか）を1つ入れる

## 本数・時刻・投稿後の動き

正は `rules/project_s4lv_operation_system.md`「投稿量」。投稿案には、1本ごとに推奨の投稿時刻を書く。いちばん強い1本を夜の枠に置く。
