## 本文

### 番号リストの作り方

⭕ Good（P1・K1/K15）
```
 1. 検索の1ページ目が企業サイトや公式サイトばかりじゃないか。そればかりなら書きません
 2. 個人ブログが1ページ目にいても、その人が自分の体験談や写真をのせていたら書きません
 3. 自分もそのテーマで実際に体験したことを1つ以上書けるか。書けないなら選びません
```
- 各項目に「判断」まで書く（「〜ならしない」）。項目名だけの箇条書きにしない
- **長さ・語尾を揃えすぎない**（3項目が文法的に完全対称だとAI臭。上は末尾を「書きません／書きません／選びません」で少し崩している）
- 業界語（allintitle・共起語・DP 等）は裸で出さない。「企業サイトや公式サイト」のように読者の言葉で

❌ Bad
```
1. 権威性の確認
2. 競合種類の判定
3. 一次情報の壁チェック
```
→ 項目名だけ・業界語・完全対称。読者は何をすればいいか分からない

### 役割分割（P2・A1）

⭕ Good
```
AIに任せているのはこの3つ。
 1. 渡した資料をもとに下書きを最後まで作る
 2. 古くなっているところを新しい情報に差し替える
 3. 見出しの重複や並び順を整える

自分でやるのはこの3つ。
 1. リライトに使う資料を集める（この下調べも最近はAIに手伝わせています）
 2. 出てきた下書きにひととおり目を通す
 3. 変更を全部見て最後にOKを出す
```
- **台帳の「事実」欄＝本人確認済みの作業だけ**を書く（2026-09-08、「勘の書き足し」等の未実施項目を削った実例あり）
- 分担の中身を名指しできる粒度で（「資料をもとに下書き」「見出しの重複」）。「AIに手伝ってもらった」で終わらせない
- 進行形。「任せると順位が下がる作業もある」のような**線引きの理由**を1文

### 平易化の実例

| ❌ 前 | ⭕ 後 |
|---|---|
| 大手が答えを出していないキーワード | 大手メディアが意識していないキーワード |
| 大手が来ない場所 | 大手がわざわざ狙ってこないキーワード |
| 体験を1つ多く入れられるか | 実体験や構成の作り込みで中身を上回れるか |
| 裸の「大手」 | 大手サイト／大手メディア／企業サイト／公式サイト のどれか |

## 完成形（オーナー確定・投稿済み）

### Good① P1判定リスト型／型・思想（K1・K15）2026-09-07
```
ブログのキーワード選び、記事を書く前に必ず見る3つがあります。ここを飛ばした記事から、検索で沈んでいきます。

 1. 検索の1ページ目が企業サイトや公式サイトばかりじゃないか。そればかりなら書きません
 2. 個人ブログが1ページ目にいても、その人が自分の体験談や写真をのせていたら書きません
 3. 自分もそのテーマで実際に体験したことを1つ以上書けるか。書けないなら選びません

この3つを全部クリアしたキーワードだけ記事にします。自分の体験を入れられた記事は、今でも検索で上のほうに残っています。

この3つを見ないで書いた記事は、たいてい後から後悔しました。
```

### Good② P2役割分割型／AI実働（A1・訂正版）2026-09-08
```
記事のリライト、AIに丸ごと任せられたら楽なんですけどね。実際は渡せるところと自分で持つところを分けています。

任せると早くなる作業もあれば、任せると順位が下がる作業もある。
そこの線引きです。

AIに任せているのはこの3つ。
 1. 渡した資料をもとに下書きを最後まで作る
 2. 古くなっているところを新しい情報に差し替える
 3. 見出しの重複や並び順を整える

自分でやるのはこの3つ。
 1. リライトに使う資料を集める（この下調べも最近はAIに手伝わせています）
 2. 出てきた下書きにひととおり目を通す
 3. 変更を全部見て最後にOKを出す

前は下書きをかなり書き直していました。
最近はそのままでもいける精度になってきて、目を通して引っかかったところだけ直すくらいです。

それでも最後にOKを出すのは自分です。

全部を任せると順位が落ちる。それがこの分け方を変えない理由です。
```

### Good③ P3時事フック型／型・思想（K2・K15）2026-09-07
```
AIが検索結果の上に答えを表示するようになってから、短いキーワードでは個人ブログが勝てなくなりました。

たとえば「iPhone Android 違い」みたいな、みんなが狙う言葉です。ここで粘っても時間が減るだけ。私も昔はずっと粘っていました。

今はあきらめる判断を早めにしています。狙っていた言葉に大きいサイトやAIの回答が出てきたら、もっと細かい言葉に1回だけ書き直します。3語や4語の、具体的なキーワードです。それで順位が戻らなければ、その記事はあきらめます。

今は、勝てそうな細かいキーワードだけに絞って書いています。
```

### Good④ A-2会話・引用型／型・思想（K7・散文）2026-09-08
```
ブログのSEO、効くと言われたことはひととおり試してきました。

文字数を増やす。それっぽい語をあちこちに入れる。関連する話題は全部拾う。毎日更新する。
どれも順位はほとんど動きませんでした。むしろ質を落として量に振った時期は、サイト全体の評価まで下がってしまうことも。

今も続けているのはたった1つです。「この検索に、この構成で答える」を1本ずつ狙って書く。

量で押すのはもうやめました。
その分1本にかける時間を増やしています。
```
- 番号リストでない散文型。**リズムが均一にならない**よう短文（「毎日更新する。」）と長文を混ぜている

### Good⑤ Note誘導回／B一次情報・共有型（K6＋note_free_20260710 章2）2026-09-08
```
AIにタイトルを5案出させる。
ここまではたぶんみんなやってます。

でも、そこからが困る。5案のどれが検索で戦えるのか、判断する材料がない。

結局、なんとなくで1つ選ぶことになります。

AIが出す案って、全部そこそこなんですよ。大きく外さないけど、大きく勝ちにもいかない。だから横に並べてもどれも同じに見える。

私は5つの基準を何個満たしてるかで数えて選んでます。

1つだけ言うと「読者が心の中で使ってる言葉に近いか」。きれいにまとめた言い方より、その人が実際に困ってる言い方のほうがちゃんと自分ごとに聞こえるんですよね。

▼自己リプライ（本文の直後に自分でぶら下げる。末尾に記事URLを付ける）
5つ全部書くと長くなるので、AIに採点までやらせるプロンプトごと無料記事にまとめてあります。キーワードと伝えたいことを貼れば、5案を基準ごとに採点してイチオシを1つ返してくれます。
```
- 誘導回の形：本文にURLなし → 自己リプライで「2つ目の山」＋URL。有料記事なら概念のチラ見せまで
