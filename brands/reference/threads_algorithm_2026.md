## 基本原則：会話速度モデル

Threadsは「会話がどれだけ速く・深く続くか」を主要シグナルとする。ビューの相当割合が返信コンテンツ自体から生まれるとされる。

- **投稿直後30分〜1時間の反応速度が生存/拡散を左右する**（この窓で反応が薄いと配信が絞られる）
- **投稿者本人がリプライに返信すると、拡散が大きく伸びる**（複数の解説記事で「いいねの最大150倍相当」「+40%超のリフト」等、数値は情報源により差があるが方向性は一致：著者の再エンゲージメントが最重要級のシグナル）
- 返信が返信を生む「reply-to-reply」の連鎖が最大の伸びを作る

## ペナルティ：エンゲージメントベイト

- 「YESとコメントして」「絵文字だけでもコメントして」のような**低努力な反応を要求する文言**は、Meta（Mosseri）が公式に問題視を明言しており、検出・下位表示の対象になっている（2024年10月に言及、継続的に精度向上中）
- 一方、**投稿内容に即した具体的なCTA**（例：役立つリスト投稿の「保存しておいてください」）はこの対象とは別物と考えられる。空虚な反応要求と、内容に紐づく行動喚起を区別する

## s4lvへの運用上の含意（2026-08-23確定）

- **現状の自動投稿基盤（Apps Script、07:30/12:00/21:30の投稿しっぱなし運用）には「投稿者本人の直後リプライ対応」が構造的に欠けている**。これが実践できれば理論上もっとも伸びしろの大きい打ち手
- ユーザーの実働時間は不定期（特定の時間帯を返信専用枠として固定できない）。そのため**固定スロット設計はせず、手が空いたタイミングでその日の未返信投稿にまとめて対応するベストエフォート運用**とする
- KPIログ（`brands/s4lv/kpi_weekly_template.md`）で「返信できた投稿・できなかった投稿」を記録し、4週間後の`/notekaigi`再検証で、返信対応の有無と反響の相関を実測データとして確認する

## 2026年9月再調査で追加した論点（公式事実 / 業界分析 / X実測 を分けて記載）

### 公式事実（Meta Newsroom・The Verge・TechCrunch）

- 2026年6月、ThreadsのMAUが5億人に到達。Meta は成長の主因を**フォロー外発見ではなく Communities（コミュニティ）**と説明
- **Local Communities**：日本・韓国・台湾で母語タグから開始。日本語アカウントは「日本語コミュニティ／話題タグへの定着」が発見経路になる
- **Dear Algo（2026年2月）／Your Algo（2026年6月）**：読者が「もっと見せて／減らして」をフィードに指示できる（公開／非公開・1〜7日）。→ **幅広い話題を週替わりで出すより、3テーマ以内で一貫**した方が、残った読者のAlgoに残りやすい（s4lvは2本柱＝型・思想6割／AI実働4割で対応済み）

### 発見経路は4つ（2026年後半は Following ではなく For You / Communities 寄り）

1. 自分の投稿が For You に乗る（初速×トピック一致）
2. コミュニティ内フィード（日本なら母語ローカルコミュニティ）
3. 他人の人気投稿への中身のある長文リプ（その投稿の閲覧者に自分が出る）
4. Instagram グラフ（IGプロフィール閲覧が Threads のフォロー予測に効く、と複数解説が Meta 文書を引用）

### 業界分析で繰り返される重み（Meta の数値公開ではない）

- **返信 ＞ リポスト ＞ いいね**。いいね単体では広がりにくい
- **初速（投稿後30分〜1時間）** が累計いいねより重要。最初の1時間で反応が足りないと配信が頭打ち
- 短い「了解」より、ある程度の長さの返信（8語以上、等の観測あり）が会話継続とみなされやすい。→ 締めで「経験／選択／賛否 のどれで答えればいいか」を先に渡すと長い返信が付きやすい
- 画像付きがテキスト単体より強い、という観測（非公式）。s4lv は現状テキストのみ・基盤の画像対応は未確認
- 死にやすい書き出し：「〜する方法をまとめました」「今日も学びをシェア」「知らないと損」「保存推奨」「拡散希望」（s4lv は `feedback_s4lv_threads_writing_style.md` で1行目禁止・qa_post.py で WARN）

### 収益化（伸びた後が空だと意味がない）

- よくある欠落：投稿が伸びる → プロフィールが「何者か不明」 → リンク先が弱い → 会話が資産にならない
- 最低限の受け皿：プロフィール1行で「誰の・何の・次の行動」／代表的な主張を固定投稿へ／リンクは bio・本体に置かない／伸びた投稿の自分リプに続きや資料を後出し
- s4lv の受け皿：プロフィールは 2026-08-19 改訂済み。**固定投稿は未設定（要検討）**

## 未検証・要フォロー
