# note運用メモ：今日の注目／今週のイチオシと、s4lvアカウントでの扱い

対象アカウント
- note: https://note.com/salvami77（表示名 s4lv）
- X: https://x.com/cfrms4lv
- Threads: https://www.threads.com/@cfrms4lv

このメモの目的
- 「今日の注目記事」「今週のイチオシ記事」に載せるための専用施策を、やる／やらないで切る
- Claude Codeが記事案・改稿・X投稿を出すときの判断基準にする
- 本業（検索で勝つブログの型を売り、有料記事へつなぐ）を壊さない

最終判断（先に読む）
- 載せることを独立KPIにしない
- ハッシュタグHack、相互スキ、生活エッセイへの路線変更はしない
- 入れてよいのは「現場記録の無料記事を年に数本」だけ
- 理由：編集部枠は人手選考で再現性が低く、今のアカウント規模（noteフォロワー約29、X約109）ではコスト負けする。ただし「失敗の現場を一人称で書く」は有料の証拠にもなるので、載らなくても資産になる

## 1. アカウントの前提（この人は誰か）

立ち位置

- 本業はテレビ・エンタメ系の特化／トレンドブログ
- 主張している実績：最高月間170万PV弱、アドセンス月収65万円
- noteは「10年で残ったアクセスの型」を商品化する場所

noteの役割分担（現状）
- 本丸：固定の有料記事（約¥4,980）「狙ったキーワードで検索1位へ導く…」

Threadsに工数を割かない

## 2. 今日の注目／今週のイチオシとは

公式の定義（確定）
- 編集部が人の目で拾うキュレーション。アルゴリズムの急上昇・人気ランキングとは別
- ヘルプに書いてあるのは「どこで見るか」だけ。文字数・タグ・時間帯の公式条件はない
- 編集部が総集編で挙げている中身：日常の気づき、人生のエピソード、新しい挑戦の記録、推しへの想い、トレンドの考察
- 2025年は「今日の注目」に約4,700本。年末にジャンル別ベスト30も出す
- 見る場所：https://note.com/recommend 、マガジン https://note.com/notemagazine/m/mf2e92ffd6658 、公式X @note_PR

運用の形
- 今日の注目：サイト＋マガジン＋公式Xが朝夜に数本紹介
- 今週のイチオシ：水曜の公式X。今日の注目からさらに少数
- その上に「今月のおすすめ10選」がある
- クリエイター体験談では 今日の注目 → 公式X紹介 → 今週のイチオシ と段が上がる、という整理がある（公式用語ではない）
- 「選出確率0.05%」は公式数字ではなく個人の概算。参考止まり

急上昇・注目キーワードは別枠。PISAやiPhone発表のような話題記事が並ぶ。編集部イチオシとは混ぜない

## 3. 実際に載っている記事の特徴（2026年8〜9月の実例から）

載りやすい型
- 一人称の場面がある
- タイトルが文または場面（手順名ではない）
- その人にしかない観察・失敗・継続の記録
- 最後まで無料で読める
- 売り込みが薄い
- 具体物がある（家、駅、本棚、旅、仕事の一日）

載りにくい型
- テンプレのハウツーだけ
- 「完全公開」「今すぐ診断」「保存版」
- 誰でも書けるまとめ
- 途中で有料の壁
- CTAと実績の連打
- 抽象スローガン

実例（タイトルだけ）
今週のイチオシ（2026-09-09）
- 娘の実家をつくりたい。37歳女、平屋を建てる
- なくなりそうな駅舎5選
- 本屋を始める僕の、人生を形作った10冊
- 愛し続けられると思っていた私が、20年目で気づいたこと
- 会社で泣いたことはあるかい

今日の注目の例
- 「今日は何をしよう」で、もう疲れている。大人にも時間割が必要だ
- 福島旅行
- 住み始めて一年の感想「キッチン編」
- 50の本屋さんと50の思い出
- マリオカートで体ごと傾けながらカーブする人がタイプです
- 1500キロの自転車旅と尻
- 会社員が不動産副業を2年続けてわかったこと
- スタートアップのマーケターがClaude Codeを使い倒したら事業が伸びた話

ポイント
- ライフ寄りの比率は高いが、ビジネス・ITがゼロなわけではない
- 入るビジネス記事は「型の販売」ではなく「現場を2年見た記録」
- ノウハウでも主語が「私はこうして失敗した／続けた」なら対象になりうる

## 4. ハッシュタグ

結論：注目・イチオシ対策としてはほぼ無視してよい

使う
- 本文と一致する発見用タグを2〜4個（例：#ブログ #SEO #アフィリエイト #note）
- 公式お題・創作大賞など、編集部が読む前提の指定タグだけ、テーマが重なるとき

使わない
- #今日の注目記事 #今週のイチオシ を自分で付ける
- 本文と無関係な流行タグ
- タグのために別ジャンルを書く

理由
- 公式ヘルプも総集編も、タグを選定条件に書いていない
- 公式Xの紹介文にもタグは出ない
- noteのタグは検索・関連・お題用。編集部が読む仕組みとは別

## 5. s4lvが意識すること／しないこと

しない（専用施策）
- 注目枠のための投稿カレンダー
- 生活エッセイ・旅記事への路線変更
- Threads強化
- 相互スキ、スキ返し営業
- 「載りやすい時間帯」の最適化を本業にする
- 編集部への営業
- 有料記事を注目狙いで全文無料化（本丸は守る）

する（載らなくても資産になる範囲）
1. 無料の現場記録を年に数本
   - 日付、順位、何をやめて何が戻ったかを先に書く
   - 既存の近い資産：「トレンドブログは稼げる？」
   - 次に書くなら自然な題材：
     - 当たり記事ばかり書いて、更新を止めたらアクセスが消えた
     - 2語が公式に埋まって畳んだ話
     - リライトのたびに文面が7割かぶっていた
   - これらはXですでに短く書いている。noteに戻す価値がある

2. 現場記録のタイトルだけ一文にする
   - NG：狙ったキーワードで検索1位へ導く。完全公開します
   - OK：当たり記事ばかり書いて、更新を止めたらアクセスが消えた
   - 有料の商品名まで全部変える必要はない

3. 現場記録は最後まで無料
   - 注目に入る記事はほぼ全文読める
   - 有料誘導は末尾の1段落で足りる

4. タグは発見用に最小限

5. 公式X @note_PR を週1・5分だけ見る
   - 「今週、ビジネス寄りの何が載ったか」を確認するだけ
   - 投稿計画は変えない

既存無料記事の使い分け
- 集客・手順：アフィリの始め方、解析ダッシュボード、アドセンス合格 → 現状維持。注目は狙わない
- 信頼・証拠：トレンドブログ論、更新停止の記録、畳んだキーワード → ここだけ編集部の型に寄せてよい
- 有料：固定の型記事 → 商品として守る。注目用に書き換えない

## 6. Claude Codeへの指示（記事・投稿を出すとき）

記事を書く／直すとき
- 読者は「ブログで検索上位を取りたい個人」。一般のnote読者全員ではない
- 手順記事と現場記録を混ぜない。役割を先に宣言する
- 現場記録のときは：
  - 冒頭3行で「いつ、何が起きたか、今の結論」
  - 数字を3つ以上（月、順位、PV、期間など、公開してよい範囲）
  - 「編集部」「完全攻略」を主語にしない。一人称
  - 前回と同じ定型文を7割使い回さない
  - 末尾のCTAは有料への1リンクまで
- 手順記事のときは従来どおり結論→判断基準→手順でよい
- 注目用の感情エッセイを新規に作らない
- タイトル案を出すときは、現場記録なら「文」、手順記事なら「何が分かるか」を優先。煽り語を足さない

X投稿を出すとき
- noteの切り出しを続ける
- 1投稿1判断
- 反応が出たテーマだけ note の現場記録に戻す
- Threads用の別企画は作らない

品質チェック
- AIっぽい語尾、同じ文の3回以上の繰り返し、1文の過長を避ける
- 「その人だから書けた判断」が残っているか
- 注目に載ることより、有料の購入判断材料になっているかを先に見る
