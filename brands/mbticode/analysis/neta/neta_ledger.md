# ネタ台帳（/mbticode-neta が追記する・新しいものを上に）

ユーザーがOKを出したネタだけを記録する。**借りるのはテーマと切り口の発想まで。文言・具体例・数字・固有の言い回しは借りない。** 出典は記録用（引用・転載のためではない）。

エントリ形式：

```
### YYYY-MM-DD｜テーマ（1行）
- 出どころ：（区分：MBTI×恋愛／恋愛テーマ）投稿URL・投稿者・日時・数字（表示／いいね／保存／リポスト／返信）と反応率
- 源流か派生か：
- 何が響いたか（構造の観察）：
- 自分の切り口案：（reference のどのタイプ特性を使うか・借りない要素）
- 状態：候補／投稿に使用（日付）／Note記事の企画候補／見送り（理由）
- 自分の投稿での結果：（数字が取れたら）
```

**Note記事化の目安**：自分の投稿で、複数の指標（Views・Likes・Replies・Reposts・Quotes）で反響があり、それが複数回あったテーマを、Note記事の企画候補に昇格する。

**観察対象アカウント**（反響の上位に2回以上出たアカウントを自動で溜める。一発屋・「採用しない型」のアカウントは外す）

| アカウント | 出現回数 | 最終確認 | メモ |
|---|---|---|---|
