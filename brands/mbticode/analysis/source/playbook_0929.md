# SNS分析資料（X / Threads）完全版
最終更新: 2026-09-29

最終目的: note有料記事の購入母数を増やす
中間目的: 表示 → 反響 → フォロー / 興味 → 送客
使い方: 投稿本文と数字をAIに渡し、この資料の手順で診断・改善稿まで出す

## 0. この資料の読み方（最重要）

一般論の寄せ集めにしないため、すべての主張に確度を付ける。

| 記号 | 意味 | 分析での扱い |
|---|---|---|
| [公式] | プラットフォームまたは公開コードが言っている | 設計の前提にしてよい |
| [公開コード] | Xの公開リポジトリ（x-algorithm）由来 | 係数の大小と符号は使う。件数の掛け算はしない |
| [研究] | 査読論文・再現された心理実験 | 人の行動仮説の主軸にする |
| [観測] | 大規模データや運用現場の反復観察。公式ではない | 仮説。自アカで検証する |
| [通説] | 発信者間で広がっているが根拠が割れている | 断定禁止。検証項目にする |
| [神話] | 反証または過大解釈がある | 使わない |

分析AIへの命令:
- [公式][公開コード][研究] で説明できることは、それで説明する
- [観測][通説] は「仮説」と書く
- 数字の母数が小さいときは中身の優劣を断定しない
- 「アルゴリズムに嫌われた」を原因の第一選択にしない

## 1. 何のための分析か

SNS投稿の成功は、note購入そのものではない。
購入は note 側（無料部分・価格・証拠・対象一致）で決まる。
SNSは前工程である。

発見（表示）→ 停止（フック）→ 理解（読了）→ 反応 → 興味（プロフィール・フォロー）→ 送客 → 購入

1投稿の主目的は必ず1つにする。

| コード | 主目的 | 主指標 | 副指標 | 失敗の典型誤読 |
|---|---|---|---|---|
| A 拡散 | フォロワー外に届く | 表示、リポスト、引用、コピー共有 | いいね | いいねだけで成否を見る |
| B 会話 | 意見や体験が返る | リプ数と質、返信の往復 | いいね | 煽りでリプを稼いで成功と見る |
| C 蓄積 | 後で使いたくなる | ブックマーク | 表示 | 保存されない＝価値なしと即断 |
| D 関係 | 発信者を追う | プロフィールクリック、フォロー | 固定投稿 | バズったのにフォローが増えないのを無視 |
| E 送客 | noteへ動かす | リンククリック、プロフィール経由 | 購入はnote側 | リンクを置いただけなのに売れないと嘆く |

推奨構成（週次、出発点）:
- 期待感（専門・結果・型）40–50%
- 親近感（過程・失敗・対話）40–50%
- 明示送客 10–20%

販売偏重は到達と関係を壊す。[観測]

## 2. 漏斗診断

自分の直近12–20投稿の中央値と比較する。業界平均は使わない。

| 表示 | 反応率 | 読み | 次にやること |
|---|---|---|---|
| 高 | 高 | 再現候補 | 部品を抜き出して台帳へ |
| 高 | 低 | 届いたが止まらない / 動かない | フック以降の心理と本文 |
| 低 | 高 | 中身は合うが配布不足 | 同じ主張で1行目・形式・時間を変える |
| 低 | 低 | 未到達＋未適合 | テーマ選定から。添削は後回し |

母数ルール:
- 表示が極端に少ない投稿で「文章が悪い」と断定しない
- リプ0を「会話設計失敗」と言ってよいのは、表示が中央値以上のとき
- リンククリック欠損時、送客成否は保留

## 3. 人の心：反応が起きない本当の理由

アルゴリズムは「人が何をしたか」の予測器である。人が動かない投稿は、予測確率が低い。先に人を見る。

### 3.1 反応のコスト階層 [研究]

公開性が上がるほどコストが上がる。

1. 見る（私的、ほぼ無料）
2. いいね（低コスト、関係の合図）
3. 保存（私的だが「後で使う」意思）
4. プロフィールを開く（興味の投資）
5. リプライ（公開自己提示。間違えたくない）
6. 引用・リポスト（自分のフォロワーに顔を出す）
7. リンクをクリックして課金（金銭＋失敗回避）

Swani & Labrecque (2020, Marketing Letters) [研究]:
- いいね / リアクション → 主に関係・親近
- シェア → 主に自己提示（自分がどう見られるか）
- コメント → 関係と自己提示の両方

分析含意:
- いいねだけ多い = 「嫌いではない」まで。公開コストを払う理由がない
- リプが多い = 自分の言葉を置ける余地がある
- 拡散が多い = シェアする側が賢く / 親切に見える
- 保存が多い = 実用価値。noteの「使える系」と接続しやすい
- プロフィールが多い = 投稿より人へ興味が移った

### 3.2 なぜシェアするのか [研究]

Jonah Berger STEPPS（Contagious）:
- Social currency: シェアすると自分がよく見えるか
- Triggers: 日常のきっかけと結びつくか
- Emotion: 高覚醒感情か（驚き・怒り・畏敬・興奮）。満足や穏やかさは拡散しにくい
- Public: 他者の行動が見えるか
- Practical value: 他人に渡す実益があるか
- Stories: 語り直せる物語か

Cosme & Falk ほか (JEP: General, 2022) [研究]:
人は「自分に関係する」または「知っている人に関係する」と感じた情報をシェアする（value-based virality）。

分析質問:
- これをリポストした人は、賢く見えるか、親切に見えるか、同じ立場の仲間に見えるか
- 友人に送る文が1文で浮かぶか
- 感情は高覚醒か、ただ正しいだけか

### 3.3 なぜスクロールが止まらないのか [研究]

注意は希少資源（Simon の注意経済）。

Loewenstein (1994) 情報ギャップ理論 [研究]:
- 好奇心は「知っていること」と「知りたいこと」の隙間で起きる
- 隙間は適度が強い。何も知らない巨大ギャップも、全部見えたゼロギャップも弱い
- 未完了は不快で、閉じたくなる

分析質問:
- 1行目で「自分の話だ」と分かるか
- 答えの一部だけ見せて、残りが気になるか
- あるいは1行目で結論まで出して、読む理由を消していないか

### 3.4 なぜ「いい内容なのに反応ゼロ」が起きるか [研究]

1. 抽象: イメージが湧かない
2. 自分ごと不足: 対象が「みんな」
3. 公開リスク: 無知に見られる、勧誘に見える、炎上
4. 損失回避（Kahneman & Tversky）: 得より損を避けたい
5. 用事の完了（Jobs to be Done）: 読み終わった時点で次の行動が消える
6. 認知負荷: 長い、主張が複数、流暢性が低い
7. 信頼不足: 初見に「買え」「信じろ」は高い
8. 互恵の不在: 一方的な告知
9. 報酬予測: いいねは社会的報酬（Lindström et al., Nature Communications 2021）。読者側も見返りが見えないと動かない
10. 同調: 既に反応がある投稿は追加されやすい。初速ゼロは心理的にも不利

### 3.5 投稿を心理部品に分解する

AIは感想ではなく、この格子で採点する（各 0–2）。

| 部品 | 0 | 1 | 2 |
|---|---|---|---|
| 自己関連 | 誰向け不明 | 層は見える | 一人称で浮かぶ |
| 具体 | 抽象語のみ | 例が1つ | 数字・場面・前後 |
| 情報ギャップ | 結論先行で閉じる | 弱い問い | 適度な未完了 |
| 実用 | 感想だけ | ヒント | 渡せる型 |
| 社会的通貨 | シェアすると微妙 | 同意できる | シェア側が得する |
| 高覚醒 | 平坦 | 軽い意外 | 驚き / 怒り / 安堵の落差 |
| 物語 | 箇条書きだけ | 変化の片鱗 | 前後が追える |
| 反応余地 | 閉じた宣言 | 弱い問い | 体験を置ける隙間 |
| 公開安全 | 極論・攻撃 | 普通 | 同意しやすい温度 |
| 次行動 | なし | ぼんやり | プロフィール / 保存 / noteの理由 |

合計ではなく、目的に対応する部品だけを重視する。
A拡散なら社会的通貨と高覚醒。C蓄積なら実用。E送客なら用事の残し方。

### 3.6 note購入までつながる心理

SNS上で買わせない。買う直前の障害を減らす。

購入者が払うもの: お金、失敗した自分になるリスク、読む時間、営業された感覚。

SNSで先に渡すべきもの:
- この人は観察している（具体）
- 自分の問題を言い当てている（自己関連）
- 無料でも得した（互恵）
- 有料側にしかない続きがある（適度なギャップ）
- 同じ立場の人が動いている気配（社会的証明）

無料部分やSNS本文で結論が完結すると、スキは増えて購入は減る。[観測]

## 4. Xアルゴリズム（2026-09時点）

### 4.1 仕組み [公式][公開コード]

Xは For You を、候補収集 → 予測モデル → 重み付き合成 → フィルタ で組む。

公開リポジトリ: github.com/xai-org/x-algorithm
2026-08-13 以降、本番寄りのパラメータが home-mixer/params/param.rs に同期される、とREADMEが述べている。

候補の二系統:
- Thunder: フォロー中
- Phoenix Retrieval: フォロー外の類似検索

モデルは視聴者がその投稿に対して取りうる行動の確率を予測し、

score = Σ (weight_i × P(action_i))

で並べる。[公開コード]

xAI自身の注記:
重みは予測確率に掛かる係数であり、生の件数の倍率ではない。
「リプ1 = いいね10」と件数換算してはいけない。

### 4.2 公開重みの向き（2026-08同期値の二次報告）

一次ソースは param.rs。複数解説が一致しているのは符号とおおよその順位。値は変わりうる。

正の側（その行動が起きそうと予測されると得点しやすい）:
- リンクコピー共有（Share via copy link）が最大級
- 相互フォロー相手の投稿へのリプは通常リプより大きい、という報告
- リプ、引用、DM共有がいいねより上
- フォロー
- リポスト
- いいねは小さい正
- 投稿クリック、外部リンクオープンはさらに小さい
- プロフィールクリック重み0という解説と、重視する解説が共存 → [通説] 保留
- ブックマークを強く数える解説と、ランキング重みなしとする解説が共存 → [通説]
- dwell は予測対象だが合成重みは小さい / 0 とするコード解説がある → 読みやすさは人の側では依然重要

負の側:
- report が突出して負
- mute、not interested、block が続く

分析含意（確度高め）:
1. いいね最適化は弱い
2. 会話・引用・「誰かに渡したくなる」設計が強い
3. 投稿者がリプし返す往復は会話の質と追加表示の両方に効きやすい [観測]
4. ミュートや「興味なし」を誘う煽り・釣り・無関係リプは高い
5. 外部リンクの明示ペナルティは2026コード解説では小さい。ただしリンク投稿の実測ERが弱いデータもある [観測]。原因は離脱行動と宣伝に見える心理が混ざる
6. Premium は返信の優先表示など制度上の差がある [公式ヘルプ]。弱コンテンツを救う魔法ではない

### 4.3 Xで伸ばす施策（確度付き）

採用してよい:
- 最初の1行で対象と未完了を置く [研究 + 観測]
- リプが付く設計（体験質問、二者択一、反論余地）
- 投稿直後に自分から会話を育てる [観測]
- 引用されやすい独立した一文を置く
- スレッドで滞在と追加クリックを取る [観測]
- リンクは「本文で価値 → 必要ならURL」。必ずリプ1に置けは [通説]。A/Bする
- 投稿間隔を空け、連投で自分の投稿同士を食わせない [観測]

採用しない:
- ハッシュタグ大量
- 「いいねして」だけで伸ばす
- 相互リプ回りだけの初速工作
- 正確な「リプ27倍」を教義にする（年とファイルで数字が違う）

### 4.4 X分析で見る数字

必須: 表示、いいね、リプ、リポスト、引用、ブックマーク
重要: プロフィールクリック、リンククリック、投稿起点フォロー
補助: 詳細展開、メディア再生

読み:
- 表示高 × リプ低 = 同意はされても発言コストを払えない
- 表示高 × ブクマ高 × 拡散低 = 私的に有用。社会的通貨が弱い
- 表示高 × プロフィール高 = 人への移行。D成功
- 表示高 × リンク低（E目的）= 本文で用事が終わったか、リンクが早い
- 表示低 × 反応高 = 配布の問題。テーマは残す

## 5. Threadsアルゴリズム（2026-09時点）

### 5.1 仕組み [公式に近い]

Metaは固定の公開ウェイト表を出していない。Transparency / 担当者説明の範囲:

- For You は予測型レコメンド。Following はほぼ時系列 [公式]
- 予測例: いいねしそうか、リプしそうか、クリックしそうか、プロフィールを開くか、スルーするか
- 入力に、Threads と Instagram での過去の相互作用、新しさ、既存の相互作用数が含まれる（Etienne Blanc らの説明）
- Metaは「リプがビューの約半分を占める」「会話を生む投稿が推奨されやすい」と述べている
- エンゲージベイト（コメントして、友達をタグ）は抑制されうる
- リプのリプ（1時間 / 6時間の会話継続）が入力信号になる、という整理がある
- 2026年にフィード自己調整（Dear Algo / Your Algo）が追加され、トピック適合が見えやすくなった

フォロワー数より For You 適合が効きやすい、は反復観察。[観測]
そのためフォロワーが少なくても単発表示が大きく振れる。

### 5.2 割れている通説（断定禁止）

| 主張 | 状態 |
|---|---|
| 本文リンクは表示を殺す | [通説] 2024前後は強かった。2025に Mosseri がリンク評価改善を発言。2026も報告は割れ。2026-09 Insights からリンククリック指標が消えた報道あり。自アカ比較が本命 |
| 画像必須、テキストは大幅減 | [通説] 一部計測。形式差より中身の重なりが大きいという注記もある |
| 45分で勝負が決まる | [通説] 速度は重要だが固定分は非公開 |
| リプは8語以上だけカウント | [通説] 公式未確認 |
| Instagram自動シェアよりネイティブ有利 | [観測] 検証可 |

### 5.3 Threadsで伸ばす施策（確度付き）

採用してよい:
- 会話が返る投稿（経験談、意見、具体的な問い）
- 投稿後にリプへ返す（会話グラフを生かす）
- 一貫したテーマ / トピック語
- 攻撃性をXより下げる
- リンクが目的なら本文を単体で成立させ、URL位置は本文 / リプ1 / プロフィールで比較する
- 大きなアカウントへ中身のあるリプをする（発見経路）[観測]

採用しない:
- 「1行目でコメントして」だけのベイト
- Xの喧嘩口調をそのまま貼る
- 毎回本文先頭に note URL を未検証のまま固定する
- Threadsの中央ERを自アカ目標に絶対化する

### 5.4 Threads分析で見る数字

必須: 表示/ビュー、いいね、リプ、リポスト、引用
重要: プロフィール訪問、フォロー増
欠けることあり: リンククリック（2026-09以降 UIから消えた報道）

表示の振れが大きいので、1投稿の当落でテーマを捨てない。3投稿以上の型で見る。

## 6. 媒体別の「同じ主張、違う設計」

分析AIは、1つの原稿を両媒体最適と書いてはいけない。

| 要素 | X | Threads |
|---|---|---|
| 文化 | 広場、速報、論争、引用 | リビング、共感、継続会話 |
| 強い反応 | 引用、リプ往復、コピーしたくなる一文 | リプ、リポスト、穏やかな同意 |
| 危険 | 無関係リプ、報告、興味なし | 営業感、攻撃、ベイト |
| 長さ | 短いフック + スレッドまたは長文 | 500字前後で完結しつつ問いを残す |
| リンク | 本文可。実測で弱いならリプ1を試験 | 本文成立が先。位置は試験 |
| 発見 | フォロー外検索 + 会話 | For You + トピック + 会話 |
| note接続 | プロフィールと固定が本線 | プロフィールと信頼が本線 |

## 7. 1投稿の分析手順（守る順）

1. 主目的は A–E のどれか
2. 表示は自分の中央値と比べてどうか
3. 1行目で誰の・何の話か分かるか
4. 具体があるか
5. 反応の種類は目的に合っているか
6. STEPPSのうち何が欠け、公開コストの何が高いか
7. 媒体の公式シグナルと矛盾していないか
8. プロフィールに行く理由があるか
9. Eなら、本文で用事を消しすぎていないか
10. 次に変える変数は1つか

アルゴリズムを持ち出す条件:
- 表示が低く、心理部品は上位投稿と同型 → 配布・初速・形式・リンク位置の仮説
- 表示は高いがリプが低い → アルゴリズム不足ではなく発言コストと隙間不足
- 負反応がある → 温度と対象ずれ

## 9. 出力フォーマット（これ以外禁止）

1. 主目的
2. 漏斗判定
3. 数字（中央値比。母数不足なら保留）
4. 心理診断（自己関連 / 情報ギャップ / 反応コスト / STEPPSの欠け / 損失回避と用事完了）
5. 媒体シグナル（[公式/公開コード] で言えること と [観測/通説] の仮説を分ける）
6. 効いている部品（引用）
7. 弱い部品（優先度 高中低）
8. 次の1改善（変数は1つ）
9. 改善稿（X向け1本、Threads向け1本。主張は変えない）

## 10. 改善ルール

変えてよいもの: 1行目、具体、対象の限定、反応の置き場、媒体温度と長さ、Eのときだけ note で終わる用事を1文。
変えてはいけないもの: 事実、商品の約束、未検証の新主張。

合格条件: 元より具体 / 公開コストが下がるか払う理由が増える / 検証可能な変化が1つ。

やらないこと: 購入率の本診断、表示不足を記事のせいにする、全投稿の販売化。
