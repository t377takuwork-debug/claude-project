## 1. このアカウントの戦略ポジション

売っているのは診断結果そのものではない。
「診断しても繰り返す」人向けの、パターンの読み替えと出口。

読者の用事（JTBD）候補:
1. 今の相手/自分の挙動に名前を付けたい（言語化）
2. 同じ失敗を次にやりたくない（回避）
3. 自分は壊れていないと確認したい（正当化）
4. 相手を理解する語彙が欲しい（翻訳）
5. 設計図として残して見返したい（保存→有料）

競合が多い層:
- MBTIあるある
- ラブタイプ16のキャラ診断
- 愛着スタイル解説
- 「わかる」で終わる共感投稿

差別化の核（プロフィールが既に持っている言葉）:
- 運 → 設計
- 診断結果 → 繰り返すパターンの出口
- わかる → 直せる（ただしSNSでは先に「わかる」が必要）

分析時の判定:
「MBTIあるある」で止まっている投稿は、競合と同じ土俵。
「同じ場面なのに直し方が逆」まで行く投稿が、このアカウントの勝ち筋。

## 2. 読者心理（このジャンル特有）

恋愛×診断アカウントで人が動く理由は、情報より自己物語である。

効くもの:
- 場面の再現精度（既読、追う、黙る、尽くす、正解の返事が出せない）
- 自分の汚点を綺麗な言葉にしてもらえる安堵
- タイプ名による所属（私はボス猫、と同じラベルを持てる）
- 「相手が悪い」でも「自分が悪い」でもなく「設計の食い違い」にできること（損失回避の緩和）

止めるもの:
- 診断知識の講義調。読者は教科書を求めてタイムラインを開いていない
- タイプ略語だけ先に出る（自己関連が発火する前に選別が起きる）
- 正しさだけの冷静さ。高覚醒がないと拡散しない
- 公開リプの羞恥。恋愛は他ジャンルよりコメントコストが高い
- 「Noteで設計図」が毎投稿末尾にあると、営業感で For You / 会話が死にやすい

恋愛ジャンルの反応設計:
- リプは「当てられた／違う」の二択や、自分のタイプ宣言が最も低コスト
- 引用は「これ元彼」「これ私」と自己提示できるとき伸びる
- 保存は「次に同じことが起きたら見返す」実用があるとき
- いいねは「痛い」への共感。関係の合図に近い

公開安全:
Threadsは温度を一段下げる。Xは少しだけ鋭くてよい。
相手攻撃・特定の実在人物攻撃は負シグナル（ミュート、興味なし）を買いやすい。
パターン批判に留める。

## 3. このアカウントの投稿を分解する追加格子

親資料の心理部品に加え、必ずこれを見る。

| 部品 | 0 | 2（このアカでの合格） |
|---|---|---|
| 場面 | 一般論 | 五感か行動が1つ（既読、映画の一言、5年後の話） |
| 痛みの名前 | 「辛い」だけ | 読者が使っている言葉（考えすぎ、伝わらない、消耗） |
| 設計への翻訳 | 精神論 | 「同じ沈黙でも直し方が逆」のような操作可能な対比 |
| ラベル | いきなりINTJ | 場面の後に、タイプは「近い人に出やすい」と限定 |
| 自己チェック | なし | 一行で自分を当てられる問い |
| 出口 | 共感で終わる | 次にやること、または「続きは設計図」の欠片だけ |
| 営業 | 毎投稿URL | 目的Eのときだけ。本文は単体で成立 |

Xサンプリングの観察（仮説）:
- 場面は取れている投稿が多い。ここは資産
- ラベルが後段に来るのは正しい順序
- 欠けやすいのは「反応余地」と「シェアした人が得する一文」
- 「心当たりある人の顔が浮かびませんか？」は問いだが、答え方が重い。Yes/Noやタイプ自己申告の方が公開コストが低い

## 4. 媒体別の適した使い方（このアカ）

### X @MBTICODE
現状仮説: 到達不足が主。フォロワー外の Phoenix に乗る材料が足りない。
今期の主目的は D関係 より先に A拡散と B会話。Eは週1以下。

向く型:
- 1行目が場面そのもの
- 3行で設計の対比
- 末尾は低コストの自己申告（「追う側 / 引く側、今どっち？」）
- 引用されやすい独立文（「追いかける熱量が、逃げる速度になっている」は既に資産）

やらなくてよいこと:
- 表示一桁の投稿を長文添削する
- 毎投稿にnoteリンク
- 診断解説スレッドを毎日

### Threads mbti_code
現状仮説: 閲覧は起きている（5.9万の自己表示）。フォロー24は、見られても人へ移行していない。
今期の主目的は B会話と D関係。閲覧をフォローに変える。

向く型:
- 「わかる」で止めてから、最後に一句だけ設計
- リプが付いたら作者が返す（会話グラフ）
- ラブタイプ名はThreads相性が良い。ただし説明なしの内輪記号にしない
- リンクはプロフィール。本文先頭に置かない実験を先に

数字の読み（このアカ）:
- Threads閲覧 ≫ X表示 なら、同じ主張でも配布面が違う。本文を全否定しない
- 閲覧が多くフォローが少ないなら、プロフィール文と固定（設計局とは何か、誰向けか）を疑う
- 両方とも反応ゼロが続くなら、問いの公開コストを疑う

## 5. 目的配分（このアカの出発点）

週の投稿をこう分ける。比率は実験で動かす。

- 場面共感（B/D）50%
- 設計の対比・出口の片鱗（A/C）30%
- 作者の観察ログ・失敗（D）10%
- note送客（E）10%

E投稿の合格線:
本文だけで「自分の繰り返しに名前が付いた」。
有料側に残すのは「出口の手順」と「掛け合わせ方」。
結論をSNSで完結させない。かといって中身ゼロの予告にもしない。

## 6. AIがこのアカを分析する追加規則

親資料の出力10項目に、次を必ず足す。

11. ジャンル適合
- 診断あるあるで止まっているか、設計翻訳まであるか
- ラベルが自己関連の前に来ていないか
- 恋愛特有の公開羞恥を下げているか

12. このアカの資産の再利用
- 既存の強い独立文（例: 追う熱量と逃げる速度 / 同じ沈黙でも直し方は逆）を指摘する
- 世界観語（設計、設計図、設計ミス、出口）を消さない。増やしすぎもしない

13. 規模補正
- Xフォロワーが一桁台のとき、成功の定義は「中央値表示を上げる」「リプ1が付く」まででよい
- 購入CVを週次KPIにしない。前工程が無い

改善稿のトーン:
- 詩的な場面は残す。このアカの声である
- 抽象語の連続だけを具体に置換する
- 末尾の問いを、答えやすい形に変える（タイプ自己申告、二者択一、場面の co-sign）

禁止する改善:
- バズ目的の煽り恋愛（「それ捨てろ」系）で世界観を壊す
- MBTI講義への全置換
- 毎回URLを足す
