# MBTICODE トレンドワード採用可否リファレンス（2026-07-30作成）

> Note記事タイトル・見出し／X・Threads投稿本文で使う恋愛系トレンドワードの唯一の正。
> `personal_data.md`は「該当する実体験があれば参照するデータベース」であり、ここに載っていないワードを排除する根拠にはしない（2026-07-30改訂・`brands/CLAUDE.md`絶対遵守ルール1のMBTICODE例外）。
> 判定基準は`brands/CLAUDE.md`絶対遵守ルール3（性的描写・断定的統計・特定個人を傷つける表現の禁止）のみ。

## 採用可

そのまま使ってよい。実体験データとの対応がなくても使用可（フィクション的な特徴描写として扱う）。

一途 / 独占 / 独占欲 / 執着 / 執着愛 / 依存 / 依存愛 / 甘え / 甘やかし / 未練 / 片思い / 両片思い / 嫉妬 / 束縛 / 冷却期間 / 復縁 / 蛙化現象 / エモい / 溺愛（多用しない。「尽くしすぎる」の言い換え程度に留める）

ヤンデレ / スパダリ / ハイスペ / 犬系 / 猫系 / 腹黒（2026-07-30追加。キャラクター類型語として使用可。ただし一人称の体験口調で使う場合は「自分もそうだった」と発信者の実体験に見せかけず、一般化された観察として書く）

サレ女 / サレ彼（2026-07-30追加。`personal_data.md`の「浮気される」構造の現代的な言い換えとして使用可）

不倫（2026-07-30追加・限定条件）：「不倫をされる側」の特徴として使う場合のみ可。「自分が不倫をする側」として一人称で語ることは捏造にあたるため不可

三角関係（限定条件）：三人称の一般論（「〇〇タイプの人に起きやすい」）としてなら使用可。一人称の体験口調では使わない

## 不採用

**寝取られ / NTR**：概念自体は「浮気される」「サレ女/サレ彼」と重複するが、この語自体がアダルトジャンル発祥という強い連想を持つため、Note規約・ルール3のリスクが高い。同内容は「サレ女/サレ彼」「浮気される」で言い換える

**復讐 / 浮気復讐 / ざまぁ / 逆転**：「特定個人を傷つける表現」に寄りやすく、ルール3に抵触しやすい

**悪役令嬢 / 死に戻り / タイムリープ / 契約結婚 / 政略結婚 / 仮面結婚 / 婚約破棄 / 拾われ・捨てられた / 人生再生 / 監禁 / 強制 / 囲い込み / 托卵**：異世界・TL小説ジャンルの設定そのもの。MBTI×ラブタイプ診断という現実の行動パターン分析の前提と噛み合わない

**尊死 / きゅんです / 秒返 / 失恋飯 / ガチ婚 / 婚活**：既存の文体（内声モード・断定調）とトーンが不一致、またはMBTI診断の切り口から外れる

## 使用時の注意（共通）

- 一人称の体験口調（「自分も〜だから言える」等）で語るワードは、`personal_data.md`に対応する実体験があるか確認する。無い場合は一般化された観察表現に留める
- Noteタイトルへの適用時は`note-article.md` Step2のNG条件（タイプ名・FW名を含めない／暗い印象を与えない）は従来通り適用する
- SNS投稿への適用時は`sns_post_cheatsheet.md`の禁止語・禁止記号・語尾ルール（qa_post.py機械チェック対象）は従来通り適用する
