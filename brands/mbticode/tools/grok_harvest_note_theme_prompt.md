# Grok X反響ハーベストプロンプト（MBTICODE Note記事テーマ選定用）

Note記事の次のテーマを決めるためのリサーチで使う。`vivant/tools/grok_harvest_x_prompt.md`（VIVANT用・実績あり）をMBTICODE向けに応用したもの。
Grok（grok.com）を「ファスト」モードで実行する（エキスパートはX Premiumだと週1で上限に当たるため常用しない）。

## VIVANT版との違い

- VIVANTは「特定の放送回」に絞るが、MBTICODEは特定イベントがないため**直近60日**の期間で横断的に集める
- 対象はMBTICODE自身の投稿ではなく、**恋愛×MBTI／性格診断ジャンル全体**で反響の大きい他アカウントの投稿
- 目的は考察収集ではなく、「反響の裏にある読者の悩み」の抽出
- **ブックマーク数は使わない**：Xの検索operatorにブックマーク数条件はなく、ブックマーク数自体が投稿者以外に非公開のため取得不可。代わりに「いいね・リポスト・表示数」を反響シグナルとして使う

## 使い方

1. grok.com で新規チャット。モードが「ファスト」であることを確認（「モデル選択」ボタンで切替）。
2. 下の本文の `{today}` `{60日前}` を `YYYY-MM-DD` 形式で差し替えて投入。
3. Chrome自動操作で回す場合：grok.comは screenshot/read_page/get_page_text がタイムアウトするため `javascript_tool` のみ使用。投入は ProseMirror へ `ClipboardEvent('paste')` 合成、送信は `[data-testid="chat-submit"]` をJSクリック、抽出は `window.__var` 格納→1500字スライスを並列取得（vivant版と同じ回避策）。
4. 出力は `mbticode/raw_grok_note_theme_{today}.md` として保存する。

# Role & Goal
あなたは日本語圏Xにおける「恋愛×MBTI／性格診断」ジャンルの反響リサーチ専任リサーチャーである。
指定期間内で、このジャンルの投稿のうち反響（いいね・リポスト・表示数）が特に大きいものを投稿URL付きで収集し、その反響の裏にある読者の「悩み」を抽出する。
記事の執筆・タイトル案の作成・考察はしない。収集と悩みの抽出だけに専念する。

# 選別
残す:
- 具体的な恋愛の悩み・失敗パターン・関係性の苦しさが書かれた投稿（引用RT・リプライで「わかる」「当てはまる」の反応が付いているものを優先）
- 「あるある」系でも、背景に具体的な悩みが読み取れるもの
- 長文の悩み相談スレッド（親＋主要な連投も辿る）

捨てる:
- 診断結果の羅列だけで悩みが読み取れない投稿
- 単なる「当たってる笑」のようなエンタメ消費のみの投稿
- 特定個人への誹謗・特定できる実名を含む投稿
- 根拠のない断定、釣り、同一文面の量産（代表1本に集約し追加URLを添える）

# Constraints
1. すべての主張にソースURL。URLがないものは出さない。
2. Yahoo!検索結果ページ・X検索結果ページ（/search?...）は出典にしない（個別投稿・個別記事URLのみ）。
3. 根拠のない予測（「〜と考えられます」）は書かない。実投稿とWeb記事の事実のみ。
4. 反響が小さい投稿より反響が大きい投稿を優先。同じ主張は代表1本＋追加URL。
5. 該当する高反応投稿がない検索クエリは「該当なし」と正直に報告する（捏造しない）。
