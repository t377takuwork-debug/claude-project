# S4LVnote の使い方

## 始める
1. Claudeデスクトップアプリで「Code」を開き、**このフォルダ(`S4LVnote`)を選ぶ**(親のフォルダで始めると、このフォルダのAIの設定やブラウザの見張りが動かない)
2. noteへの下書き保存・キーワード確認・X の分析で、Codeの画面右上の地球アイコンで開く内蔵ブラウザを使う

## 最初に1回だけ、パソコンでやること
鍵のファイルは git に入れていないので、パソコンの中で写す必要がある。中身は開かずに、ファイルごと写す。
1. `UYAnote/.env.local` を、`S4LVnote/.env.local` に写す(Buffer の鍵。UYA. と同じ Buffer なので同じ鍵)
2. 次の2つを、`S4LVnote/3_広報部/スレッズ道具/` に置く(2026-10-11に、置いてあることを確かめた。別のパソコンに移すときだけ、前のパソコンのこの場所から写す)
   - `sheets_service_account.local.json`(スプレッドシートを読み書きする鍵)
   - `threads_auth.local.json`(スレッズの過去の投稿を読む鍵)
3. 確かめる：S4LVnote で `python .claude/hooks/buffer_api.py channels` を実行して、一覧に cfrms4lv の X が出ればよい

## 頼み方(X とスレッズ)
- 作る：「10/10のXの投稿を3本作って」「スレッズの投稿を2本作って」
- 直す：そのまま「2本目の1行目をこう直して」と伝える(直した全文を見せてから保存します)
- 予約：「Xを予約して」「スレッズを予約して」で、まず送る内容を見せます。そのあと「予約して」で、はじめて送ります
- 分析：「Xの分析をして」「スレッズの分析をして」

## 止まる場所
1. 提案(設計の表・本文・チェックと審査の結果)を見て、直す点を言う
2. 予約の前に、送る内容と日時を見る

## 頼み方(note記事)
- 作る：「note記事を書きたい」「有料記事を書きたい」「次の記事どうしよう」
- タイトルを選ぶ：「1番」「2で」
- 構成に合意する：「この構成で」
- noteにログインを頼まれたら：画面右の内蔵ブラウザで **s4lv(salvami77)** のnoteにログインして「ログインしました」
- noteの画面で直したら：直した本文を貼って「下書きを直した」
- 公開したら：「公開しました」と公開ページのURL
- 運用の相談・数字の画面：「noteの方針を相談したい」「数字の画面を送ります」(画面のスクリーンショットを付けて)

## 止まる場所(note記事)
1. ネタを選ぶ(任意)・材料の質問に答える(資料があれば一緒に)。資料の数字や言葉に食い違いがあるときだけ、まとめて1回だけ質問が来る
2. 読者像とタイトル3案(採点つき)を見て、番号で選ぶ
3. 構成案を見て、合意か修正指示
4. noteの下書きを見て最終チェック(画像を入れる・公開メモを消す・有料なら価格と有料ラインを入れる)

審査(AIっぽさ・初心者読者)の指摘は、AIが直してから、結果の要点だけを報告します。

## 中身の見取り図
- `0_社長室/S4LV設定/` s4lv の決まり(アカウント・読者像・実績と開示・運用の全体)
- `0_社長室/` 学びの台帳・記事の一覧・投稿のネタ台帳
- `1_企画部/` `2_商品開発部/` note記事の手順(`社員.md`)・記事の決まり・原稿(`原稿/`)
- `3_広報部/` X とスレッズの決まり・手順(`社員.md`。noteの下書き保存もここ)・投稿ファイル(`投稿文/`)・記録・分析
- `参考資料/` 数字を記録するときの見本
