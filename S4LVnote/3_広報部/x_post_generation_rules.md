# X投稿の決まり（s4lv / @cfrms4lv）

声と書き方は、`3_広報部/s4lv_voice.md` のうち **「使わない言い方」「書き方の形（読点・改行・記号）」「ばらつきの決まり」** だけを使う。それ以外の声の細かい決まり（語尾の表・主語・1行目の入り方・見本・提案前の自己チェック）は、Xでは使わない。基本の声は、肩の力が抜けた、あたたかい話し言葉。
広め方の仕組みの資料は `../brands/reference/x_algorithm_2026.md`（決まりの根拠として残す。投稿ごとに値を書く必要はない）。

## 守ること

1. 実際にあったこと・やったこと・数字として書く部分は、作らない。台帳の事実・ジャーナル・オーナーが確かめたことだけを使う
   - 意見・気づき・考え・一般論・外の話題への見方は、体験の裏づけがなくてよい。ただし、意見の裏づけのための体験談は足さない
   - 確かめていない情報を、確定した実績として言い切らない
   - 台帳の「事実」欄の細かさや言いかえ欄に合わせる必要はない。自分の言葉で書いてよい。オーナーが訂正した内容だけは、訂正どおりにする
2. 開示：番組名・タイムテーブルなど定期更新の記事だと分かる言葉・ブログ名・URLは出さない（正は `0_社長室/S4LV設定/personal_data.md`「開示ルール」）
3. noteの規約：性的な描写・言い切った統計・特定の人を傷つける書き方をしない
4. ふだんの言葉で書く。通報・ミュート・興味なしを誘う煽りは書かない
5. 同じテーマ・同じ角度を、直近の投稿（XとThreads）と重ねない
6. リポストのお願いや、キャンペーン型の投稿はしない

## 反響の狙い（書く前に1つ決める）

| 狙い | どんな投稿か |
|---|---|
| A 会話・引用型 | 返信・引用したくなる投稿。反論できる断言、予測、抜けている事実の指摘など、返したくなる隙を作る |
| B 一次情報・共有型 | 人に送りたくなる、それだけで完結した投稿。「保存してください」とは言わず、中身が完結していることで閉じる |

- 1つの投稿に両方を混ぜない。AとBの比率は決めない
- 狙うのは「フォローしていない人が返信・引用・共有したくなること」。いまのフォロワーとの会話だけを狙わない

## 形

- 本文にURLとハッシュタグを入れない（誘導の回は、自己リプライにURLを書く）
- 見出しには、日時・柱・元ネタ・狙い（A／B）・推奨の投稿時刻と、`／形：○○／入り方：○○／終わり：○○`（`s4lv_voice.md`「形の引き出し」の語彙）を書く
- 本数・時刻・柱の比率・投稿後の動きは、`0_社長室/S4LV設定/project_s4lv_operation_system.md`「投稿量」のとおり。いちばん強い1本を夜の枠に置く

## Note記事への誘導の回

- 週1本を目安に、型・思想の投稿のうち1本を誘導の回にする。1日に2本以上は入れない
- ネタ元は `0_社長室/note_article_index.md` の章。「直近X誘導日」が空欄か、いちばん古い記事を選ぶ。使ったら、その欄に日付を書く
- 本文は、章の考え方を見せるだけにする。売り込みの一文は入れない。有料記事は、考え方を見せるところまで（キーワードの選び方の決まりや、記事構成の型を、そのまま文章で渡さない）
- URLは本文に入れず、自己リプライに、そのままコピペできる形で書く。自己リプライには「読む理由」（何が分かるか）を1つ入れる
