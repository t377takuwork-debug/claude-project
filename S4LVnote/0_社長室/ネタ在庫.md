# ネタ在庫（s4lv・X）

**事実の台帳（`x_neta_daicho.md` のK・A）は、オーナーが実際にやっていること。こちらは、外の話題を分析して取り出した「テーマ」と「別の切り口」の在庫。** 投稿の中身（事実）は、台帳か実績データから出す。

## 在庫の量と上限

| 項目 | 値 |
|---|---|
| 目標 | 2週間分（1日3本×14日＝約42本分）の「未使用の切り口」 |
| 上限 | テーマ30件。1テーマの切り口は最大3つ |
| 残りの数え方 | 状態が「未使用」の切り口の数 |
| 補充の目安 | 未使用の切り口が14（約5日分）を切ったら、`/buzz-why` を回す |

## 登録の流れ

1. `/buzz-why` が、バズ投稿を分析する（理由・型・ネタ・別の切り口を取り出す）。
2. 分析した結果を、1テーマ1ブロックで、下の「在庫」に登録する。**他人の投稿の全文は、書かない**（URL・数字・構造のメモだけ）。
3. 点数が5未満のものは、登録しない。
4. 上限を超えるときは、点数がいちばん低いものを、新しいものと入れ替える（同点なら、古いほう）。

## 点数（0〜10。高いほど残す）

各観点を0・1・2で付けて、足す。

| 観点 | 2点 | 1点 | 0点 |
|---|---|---|---|
| s4lvとの一致 | 台帳のK・Aに結びつく | 意見としてなら言える | 結びつかない |
| 根拠の強さ | 自分の事実・公式で確認できた | Xの主張のみ | 不明 |
| 鮮度 | 普遍的、または2週間以内 | 1か月以内 | それ以上 |
| 反響の根拠 | フォロワーの割の比率が3倍以上、または保存率1%以上 | ある程度 | なし・不明 |
| 既出との距離 | 直近2週間の投稿と近い話がない | 話は近いが、切り口が違う | 近い |

## 使うときの決まり

- 同じテーマを、直近の投稿と続けて使うときは、切り口の軸（読者・場面・結論・形）のうち**2つ以上を変える**。
- 同じテーマは、同じ週に2本まで。同じ元ネタは、同じ週に1本まで。
- 元の投稿の数字（いいね数・金額・割合・件数）は、本文に使わない。数字は、自分の実績データか、公式の一次情報（出典が分かるもの）だけ。
- 元の投稿の言い回し・造語・具体例は、使わない。入り方・具体例・結論の並びのうち、2つ以上を変える（`/buzz-why` の「元との距離」）。
- 使ったら、その切り口の状態を「使用済」にして、使用日を書く。
