# Xネタ在庫（s4lv・X）

リサーチの候補のうち、s4lv で使える元ネタを溜める。使い方の決まりは `3_広報部/x_post_generation_rules.md`「リサーチ候補の使い方」が正（ここには写さない）。

## 決まり
- 溜めてよいのは、次の3つがそろう候補だけ：同じテーマの中に自分の事実（台帳・ジャーナル）がある／借りられる型がある／最近使ったネタと重ならない
- 合い方は2段階
  - ◎：自分の事実が、同じテーマで台帳・ジャーナルにそのまま書いてあり、伸びた理由が「再現できる要素」まで書けている（`/buzz-why` で分析した行は、ふつうこちら）
  - ○：3つはそろうが、どちらかが弱い（X投稿AIが選ぶついでに足した行は、ふつうこちら）
- 上限は30件。足すときに30件なら、合い方の低い行（○が先、同じなら登録日が古い行）と入れ替える。足す候補のほうが低いときは、足さない
- 登録から14日たった行は消す（最新の話題が古くなるため）
- 使ったら、その行を消す（使ったことは、posts_x.txt の見出しの元ネタに残る）
- 他人の投稿の本文は書かない（URL・数字・型のメモだけ）

|---|---|---|---|---|---|---|
