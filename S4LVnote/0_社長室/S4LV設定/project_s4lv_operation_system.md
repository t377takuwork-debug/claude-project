## マネタイズ導線

```
Threads（認知・バズ）→ X（信頼構築・2本柱）→ Note無料（週1）→ Note有料（月1）
```

1. **AI実働投稿は有料記事の「生きた証拠」**：「この型は現役で機能している」を日々更新する役割。単体で売り込まない
2. **X→Noteのチラ見せ設計**：有料記事の各章の概念を投稿テーマとして小出しにし、CTAなしで辿り着かせる
3. **無料記事＝有料への装置**：中間CTA×2／「自力完結の錯覚を壊す一文」をテンプレ直後に／**有料記事で売るのは「生存構造・思考プロセス・リスク管理」「効率化・自動化の仕組み」に限定し、個別のキーワード選定ルール・記事構成テンプレのテキスト直接開示はしない（2026-08-21改訂。詳細は`project_s4lv_note_article_process.md`マネタイズ設計原則）**
4. **価格戦略**（2026-08-19 `/notekaigi`で実態確認・方針修正）：固定表示中の既存有料記事（¥4,980）はそのまま据え置く（n=1の購入実績がどの記事に紐づくか不明なため、下げて既存実績を壊すリスクを避ける）。**次に作る新規有料記事は当初ロードマップ通り980〜1,980円（3,000〜5,000字・即効性）から再開**し、購入実績と感想を貯める→引用できる状態になったら4,980円帯（10,000字超）へ
5. **告知スタンス固定**：「売るのは未熟。だからこそ中身の手順化に徹底的にこだわった」

### マネタイズ目標（2026-08-21確定）
- **note有料記事販売をメインとした月50万円以上**。期限は未設定（現時点では考慮しない）

### 撤退基準（ユーザーのマスターデータ準拠）
- 週20時間以上×1ヶ月継続で目標収益（月50万円）の20%以下 → ピボット
- 3回のアプローチ変更でCV率・エンゲージが微増もしない → ピボット
- 「資産の持続性」が絶対軸。収益の即効性は二次評価

## プロンプト集（コピペ用）

### X・Threads投稿
```
/s4lv-post [日付]のXを3本（またはThreadsを2本）提案して
```
読むもの・機械チェック・審査は、`/s4lv-post`（`../.claude/commands/s4lv-post.md`）の手順が持つ。

### Note無料記事（構成まで）
```
s4lvのNote無料記事に着手。テーマ：[テーマ]。
Step1〜3（前提確認→タイトル3案を95点基準で採点→構成案）まで進めて、
構成の合意を取るまで本文は書かないで。
```

### Note本文
```
合意した構成で本文を執筆（Step4〜6）。4,000字以上・テーブル禁止・語尾3種混在。
AI臭さ除去の3軸で自己チェックし、qa_article.pyの結果ごと見せて。
```

### 有料記事プロモ
```
[日付]公開の有料Note「[タイトル]」のX予約投稿3本を作って。
6:30予告→12:00公開告知（固定ポスト用・URL入り）→20:00リマインド（収録内容の箇条書き）。
各章の概念チラ見せ設計・本文CTAなしで。
```

### 週次KPI
```
今週の数値：X[n]・Threads[n]・Note PV[n]/スキ[n]/販売[n]。
前週比で「伸びた要因1・落ちた要因1・来週変えること1」の3点だけ。
```

### 反応が悪かった投稿の見直し
```
今週反応が悪かった投稿：[投稿文]。
決まりに照らして原因を考えて。直すべき決まりがあれば、brands/s4lv/CLAUDE.md「決まりを変える手順」で反映して。
```
