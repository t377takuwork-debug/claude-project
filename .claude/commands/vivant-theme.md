# vivant テーマ・タイトル設計

vivantのNote記事テーマを評価し、有料・無料の判断・ペルソナ設定・タイトル決定まで行うシステム。
junk_juiceの `/junk-theme` を土台に、実体験ベースではなく情報ベースで記事を作る前提に調整している。

使い方：`/vivant-theme [テーマ案]`（テーマなしで起動した場合はStep 0の質問から開始）

---

## アカウント概要

`vivant/profile.md` を参照する（ジャンル：TBS系日曜劇場『VIVANT』続編・第2シーズンのドラマ考察）。キャラクター・語り口・ターゲットが未確定の場合は、Step 0でユーザーに確認してから進める。

**一次情報の参照（必須）**：テーマ・タイトル設計時は `vivant/reference/` フォルダ（放送内容・視聴率・SNS反応・SEOキーワード・登場人物等の事実情報）を必ず参照する。架空のエピソード・数字を使わない。

**キャスト情報鮮度チェック**：`vivant/reference/vivant_characters.md` 冒頭の「最終鮮度チェック日」が7日以内ならスキップ。それ以外はWebSearchで「VIVANT 新キャスト 発表」等を簡易検索し、新キャスト・役名判明があれば追記の上、チェック日を更新する（別途スケジューラは使わない）。

## Step 0：テーマ・ジャンルなしの場合

以下がまだ未確定の場合、進める前に必ず確認する。

- ジャンル（`vivant/profile.md` に記載がない場合）
- 今回のテーマ・ネタ

「今回のテーマ（ネタ・切り口）を教えてください」と1つだけ質問する。ジャンル自体が未定の場合は先にジャンルを確認する。

---

## Step 0.5：有料・無料の判断

**この判断をせずに先に進まない。**

- **種別指定あり**：ユーザーが「有料」「無料」を明示した場合はその指定に従う
- **種別未指定**：`vivant/rules/project_vivant_copyright_and_monetization.md` の方針により**無料記事をデフォルトとする**。有料記事は、公開済み無料記事への反応（「続きが知りたい」等のコメント）が出たテーマが見つかり、ユーザーと相談の上で決めた場合のみ着手する

```
【判定】：無料記事 / 有料記事
理由：（1文で）

＜有料の場合のみ追記＞
有料にできる根拠：
想定価格：
無料パートで見せるもの：
有料パートに残すもの：
```

## Step 1：ペルソナ設定

このテーマを読んで最も心を動かされる「たった一人」を設定する。汎用的な属性ではなく、具体的な一人の人物として描くこと。

出力する項目：
- 仮名・年齢・属性・現在の状況
- 今この人が抱えている気持ち・疑問（感情レベルで）
- この記事に出会う場面（いつ・どこで・どんな気持ちで読むか）
- この記事を読んで得たいもの・変えたいもの

「このペルソナで進めますか？」と確認する。

---

## Step 2：テーマのシビア評価

以下の3名が独立した視点で審査する。忖度・曖昧な合格判定は禁止。

**【感情担当】** 「読んでよかった」「シェアしたい」「コメントしたい」と思わせる感情の山があるか。

**【逆算担当】** vivantの長期資産になるか。フォロワー増加・有料記事への導線につながるか。1回読まれて終わりの消耗品になっていないか。

**【情報信頼性担当】** 一般論の要約で終わっていないか。「このアカウントならではの整理・切り口」があるか。断定的な統計・数字を使う場合、出典を示せるか（示せない数字は使わない）。

```
【感情担当の評価】：
【逆算担当の評価】：
【情報信頼性担当の評価】：

【判定】：採用 / 却下

＜却下の場合＞
却下理由：（ロジカルに・忖度なしで）
代替テーマ案：（1案・理由付き）

＜採用の場合＞
このテーマがペルソナに刺さる理由：（2〜3文）
```

却下の場合はStep 2を繰り返す（代替案をユーザーが承認したら次へ）。

## Step 3：SEOキーワード確認（タイトル前に必ず実行）

**`vivant/reference/vivant_seo_keywords_*.md` に該当キャラクター・トピックのファイルが既にある場合は、それを優先的に使う（WebSearchでの再調査は不要）。** ファイルがない場合のみ、以下の手順で新規に調べる。

① ペルソナが実際に検索しそうな言葉を3〜5語句リストアップ
② WebSearchで実在確認・競合記事の切り口を把握
③ タイトル用キーワード1〜3語を選ぶ（複合キーワード可）
④ H2見出し組み込み用の関連ワード2〜3語をピックアップ
⑤ 新規に調べた場合は `vivant/reference/vivant_seo_keywords_[キャラ/トピック].md` として保存する（今後の記事で再利用するため）

採用基準：実際に検索されている・タイトルに入れて不自然でない

確認結果の出力（必須・引き継ぎ情報に含める）：

```
【SEOキーワード確認結果】
確認したサジェスト候補：
競合記事の主な切り口：
差別化余地（vivantならでは）：
採用キーワード（タイトル用）：
H2見出しへの組み込み候補ワード：
```

## Step 4：タイトル設計

採用テーマとSEOキーワードをもとにタイトル案を3つ生成する。

**ケープルズの4特徴（優先順位順）**
1. **得になる**（最重要）：読者がこの記事で何を得るか明確か
2. **好奇心**：「どういうこと？」と続きを読みたくなるか
3. **新情報**：「知らなかった」と感じさせる要素があるか
4. **手っ取り早さ**：「自分にも関係ある話だ」と感じさせるか

**固有ルール**
- SEOキーワードを自然に組み込む
- 否定的・暗いイメージを避ける
- 45字以内

```
案A：[タイトル]
案B：[タイトル]
案C：[タイトル]

| 評価軸 | 案A | 案B | 案C |
|---|---|---|---|
| 得になる要素 | | | |
| 感情フック | | | |
| SEOキーワード | | | |
| 差別化（vivantならでは） | | | |
```

「どの案を選びますか？または修正指示をください」と確認する。
