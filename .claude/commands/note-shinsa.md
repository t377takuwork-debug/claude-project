# /note-shinsa — Note記事 AIっぽさ・トーン審査（手動起動）

`note-ai-reviewer` サブエージェントを任意の下書きに対して起動し、審査結果をそのまま中継する。`/note-article`・`/vivant-article` では本文完成後に自動で同じ審査が走る（必須ゲート）。このスキルは「既存の下書き・公開済み記事を改めて審査したい」「修正後にもう一度だけ見たい」ときの入口。

## 呼び出し方

```
/note-shinsa <下書きのパス> [--paid] [--round N]
```

- パス未指定なら「審査する下書きのパスを教えてください」と一言だけ聞く
- `--paid`：有料記事として `qa_article.py --paid` で回す
- `--round N`：2巡目以降。直前の審査表をそのまま添えて委譲する

## 手順

1. Agent ツールで `note-ai-reviewer` を起動する。委譲文は次の4点だけ（手順の再掲はしない。審査員は `note_review_rubric.md` を自分で読む）：
   - 対象パス
   - 種別（無料／有料）
   - アカウント（パスから明らかなら省略可）
   - 巡数と、2巡目以降なら前回の指摘表
2. 返ってきた審査結果を**加工せずそのまま**ユーザーに提示する（要約・褒め足し・指摘の間引きをしない）
3. FAIL の場合、修正するかどうかはユーザーの判断。このスキルは修正しない（修正は `/note-article` 等の本文生成フローで行う）

## 完了条件

`## 審査結果: PASS` または `## 審査結果: FAIL（…）` で始まる審査表がチャットに出ていること。
