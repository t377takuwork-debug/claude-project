# template_parts（すぐ使える部品）

完成済みの記事から取り出した、そのまま貼れるHTML部品。`{{...}}` の部分だけを書き換えて、記事の該当位置に貼る。
**装飾クラスは使わず、すべてインラインstyle**（`rewrite_common_rules.md` 12章・スケルトンの注記どおり）。配色は紺×金×赤。番組の公式ロゴの色に合わせて置き換える。

| ファイル | 内容 | 使う場面 |
|---|---|---|
| `sokuho_guide.html` | 冒頭のコード（放送日／発表状況／過去の目安／目立たせたい情報／Update）。**コードの前後の文は各1文程度**（16-4） | 新規記事の冒頭 |
| `time_band_yosou.html` | 時間帯ごとのH3＋予想カード1組（「予想」バッジ・確度）。時間帯の数だけ複製する。カードの中身（企画名と根拠）は記事ごとに書く | 企画の順番が未発表の特番 |
| `haishin_guide.html` | 配信ガイド（リアルタイム／無料配信／これまでの配信）。**U-NEXTのA8リンクと計測ピクセルは提供コードのまま**（`loading`属性を足さない） | 見逃し配信のH2 |

- ここに無い部品（順位リスト・過去回のカード・FAQ）は、`template_new_article_skeleton.txt` 末尾の「部品の探し方」表のマーカーで、`draft_allstar.txt`／`draft_allstar_marathon.txt` からGrepして取り出す。
- 部品を直したら、貼った記事側も同じ内容に直す（部品ファイルは元の記事のコピー）。
- 貼ったあと `python tools/qa_draft.py {ファイル名}` を実行する。
