# 紅白歌合戦 リライト用 資料①②リサーチ

`/kouhaku-rewrite` で資料が渡されなかった回だけ、本編に入る前に実行する。資料が渡された回は読まない。

完了条件：整形した資料を `tools/output/kouhaku_material.md` に保存し、オーナーの承認を得る（承認前に `kouhaku-rewrite.md` へ進まない）。固定情報（URL・部品）は `kouhaku-rewrite.md` が正。ここでは毎年変わる情報だけを扱う。

## 基本の進め方（毎回これだけ）

1. **差分だけ読む**：draftの更新履歴の最新日付（Grep `aria-label="紅白歌合戦 更新履歴"`）より新しい発表だけを調べる。すでに反映した項目は読み直さない。
2. **確定情報は公式2つだけ**（Chrome）：NHK公式のトップ → X公式のプロフィール。この2か所で足りるときは、ここで止める。
3. 足りないときだけ、X検索 → Yahoo検索の順に広げる。

**内定・「濃厚」などの報道は確定情報として書かない。** 資料には「報道段階（出所つき）」の欄に分けて入れ、記事には「報道では〜」と出所を示すか、書かない。**「未発表」と書く前に必ず公式を読む**（ニュース検索だけで結論づけない。STARで2026-10-08に取りこぼした反省）。

## 入口（2026-10-09 実地テスト済み）

| 入口 | 取り方 | 使いどころ |
|---|---|---|
| NHK公式 `https://www.nhk.or.jp/kouhaku/index.html` | **Chromeのみ**（WebFetchはブロック） | 「新着情報」の見出しと日付を読み、新しい項目の下層ページを開く（司会 `mc77/mc_1.html`、テーマ `theme77/theme_1.html`、お知らせ `topics77/topics_YYMMDD.html`）。出場者・曲順のページは公開されたらメニューか新着に出る |
| X公式 `https://x.com/nhk_kouhaku` | **Chromeのみ**（WebFetchは402） | 公式発表の最速。画像で出る発表（出場者・曲順）は本文に出ないことがあるので、画像の有無を見る |
| X検索 `https://x.com/search?q=%23NHK%E7%B4%85%E7%99%BD&f=live` | Chrome | 公式の投稿を引用した最新の投稿。公式のプロフィールで足りないとき |
| Yahoo!ニュース検索 `https://news.yahoo.co.jp/search?p=紅白歌合戦&ei=utf-8` | WebFetch | 内定報道と、出場回数・曲名の裏取り。**約半分は無関係な記事**なので、プロンプトで第◯回に関するものだけに絞り、記事URLを出させる |
| Googleニュース `https://www.google.com/search?q=紅白歌合戦&tbm=nws` | Chrome | Yahooで0件のときだけ1回 |
| Grok | Chrome | 下の2つの場合だけ |

Chromeの作業は `tabs_context_mcp`・`navigate`・`javascript_tool`・`browser_batch` の4つを1回で読み込み、「navigate → javascript_tool」を `browser_batch` でまとめる。`javascript_tool` の返り値に `?` `=` `&` やURLが入ると `[BLOCKED: Cookie/query string data]` になるので、返す前に取り除く。Grokの操作の技術メモは `env-grok-chrome-automation`（入力欄は `.tiptap.ProseMirror`、改行つきは貼り付けで投入）。

## 段階ごとの追加

| 段階 | 調べること | 公式のほかに |
|---|---|---|
| ① 出場者の発表前 | 司会・テーマ・放送日時・出場者の発表日の予告 | 不要 |
| ② 出場者の発表後 | 紅組・白組、初出場・出場回数、特別企画、歌唱曲 | Yahoo（本文で曲名・出場回数を確認） |
| ③ 曲順の発表後 | 時間帯ごとの曲順、メドレーの中身、特別企画の位置 | 画像のみで読めなければオーナーに依頼 |
| ④ 放送後（資料②） | 実際の出演順・時間帯・変更・欠席 | Grok（下記） |

## Grokを使う2つの場合

- **任意：内定報道の拾い漏れ確認**（①〜②の直前）。2026-10-09の試験では、公式発表の部分は正確、内定の部分は噂系アカウントが中心で未確認の情報が混じった。**結果は「非確定・出所つき」で出し、記事には使わない。** 骨子：「X上の投稿だけを根拠に。一般知識・過去回の知識で補わない。①出場が『内定』『濃厚』と報じられたアーティスト（媒体または投稿者・投稿日つき）②NHK公式がすでに発表した事項。出力は表A（報道段階）と表B（公式発表済み）のみ。見つからない項目は『見つからず』」
- **④ 放送後の実出演順**：CDTV・Mステ・STARと同じく、Grokで実出演順・時間帯・SNS反応を取り、公式の曲順と突き合わせる（食い違ったら公式が正）。紅白は約50組・約4時間半と長いので、前半（19:20〜）と後半（21:00〜）に分け、30分単位を目安にする。**紅白用のプロンプトは未作成**。放送後に、曲順・欠席を事前情報として埋めた形で作る（オーナーに専用プロンプトがあれば取り込む）

## 資料の保存形式（`tools/output/kouhaku_material.md`）

```
## 資料① 第◯回 / 段階：①〜④
### 確定（公式で確認）
- 放送日時・放送局・司会・テーマ／出場歌手（紅組・白組、初・出場回数）／特別企画／歌唱曲・メドレーの曲名／曲順（時間帯ごと）
### 報道段階（非確定・出所つき）
- アーティスト／媒体／日付／表現
### 見つからなかった項目
- 項目名（公式を読んで未掲載だった旨）
## 資料② 直前回（④の後のみ）
```
