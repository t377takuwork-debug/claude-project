# Shira Notes 番組表リサーチ（ネタ発掘）

「番組表から調査して」「明日の番組表からネタ探して」等と言われたら、このコマンドの手順に従う。
**手動実行専用**：ユーザーが指示したタイミングでのみ動く。無人の自動実行（朝の定時実行など）は行わない。

## 位置づけ

- 音楽番組のキーワード一致だけでは拾えない「記事になりそうな人物・番組・話題」を、番組表の概要文を実際に読んで見つけるためのリサーチ。バラエティ・ドラマ等、音楽番組以外の概要文にアーティストの動き（新曲・活動再開/休止・独占告白等）が書かれているケースを狙う。
- ここで見つかる候補は「切り口の発見」までで、記事の事実確認そのものではない。概要文は番組表サイトの短い紹介文であり一次情報ではないため、記事化する際は改めて`/shira-keyword-article`のStep 0（資料インプット確認）に戻り、公式サイト・公式SNS等で必ず裏取りする。**概要文の言葉をそのまま記事の事実として書かない**（プロジェクト全体CLAUDE.mdの捏造禁止ルールに従う）。
- `/shira-research`（ニュース記事ベース・直近12時間限定・番組/発売情報）とは情報源・対象期間が別。両方使ってよい。

---

## 手順

### Step 1. 対象範囲の確認

デフォルトは「翌日から3日分」・時間帯18:00〜23:00（JST基準）。ユーザーが日付や日数を指定した場合はそれに従う。

### Step 2. スクリプト実行

```
python tools/research_tv_guide.py                              # 翌日から3日分・18:00〜23:00（既定）
python tools/research_tv_guide.py --date YYYYMMDD               # 開始日を指定（例: --date 20260915）
python tools/research_tv_guide.py --days 1                      # 1日分だけ
python tools/research_tv_guide.py --start 06:00 --end 09:00     # 時間帯を変更（朝ワイド帯など）
python tools/research_tv_guide.py --full                        # 時間帯で絞り込まず1日分すべて
```

収集先は bangumi.org（番組表.Gガイド）の東京エリア版。`tools/output/tv_guide_research.md` に、
指定時間帯の番組（既定の18:00〜23:00で1日あたり90〜100件前後、3日分で約270件・800行前後）が
日付ごとの見出し（`## {日付}`）で区切られ、時間帯・チャンネル・番組名・概要文つきで出力される。
ジャンルによる絞り込みは行っていない（時間帯以外は全番組が対象）。

既定を18:00〜23:00にしているのはShira Noteの主戦場（音楽番組・特番が集中する夜のゴールデン〜
プライム帯）に絞って読む量を減らすため。この時間帯外にネタがありそうな場合（朝の情報番組・
深夜のアーティスト密着番組等）は`--start`/`--end`または`--full`で対象を広げる。

### Step 3. 出力ファイルを全文Read

部分Grepで済ませない。音楽と無関係に見えるタイトルの概要文にアーティスト名や活動の動きが
埋もれているケースがあるため、必ず概要文まで含めて全件に目を通す。
**3日分（既定）はファイルが800行前後になり1回のReadでは収まらないため、offsetを使って
2回に分けて読む**（1回目: offset省略、2回目: 1回目の結果に表示される続きの行数をoffsetに指定）。
途中で切れた状態のまま候補を提示しない。

### Step 4. 候補の抽出

Shira Note（音楽番組タイムテーブル速報ブログ）の読者が関心を持ちそうな候補を、
**概要文に書かれている中身を根拠に**拾う。番組名だけで機械的に判定しない。

拾う対象の目安（初期案。運用しながらユーザーと基準を調整していく）：

| 種別 | 目安 |
|---|---|
| 新しい音楽番組・特番 | ルートの`blogs/shira_note/CLAUDE.md`のスラッシュコマンド一覧にない番組で、音楽番組らしい内容 |
| 音楽番組以外での音楽アーティストの動き | バラエティ・ドラマ・ドキュメンタリー等にアーティストが出演し、新曲・ライブ・活動再開/休止など動きが概要文に書かれている |
| 芸能人本人の大きな動き | 初出演・独占告白・卒業・脱退・活動休止など、概要文に明記されているもの |

除外：上記に当てはまらない一般ニュース・情報番組・アニメ・ドラマ本編（音楽アーティストの動きに触れていないもの）。

### Step 5. 優先順位と提示

各候補に優先度（高・中・低）を付け、根拠にした概要文の一節を引用して提示する（要約ではなく実際の文言を引用し、自分の言い換えと混同しない）。

| 優先度 | 基準 |
|---|---|
| 高 | 既存リライト対象番組の新規発表、または知名度の高いアーティストの明確な動き |
| 中 | 動きはあるが対象読者への刺さりが読みにくいもの |
| 低 | 一応拾ったが記事化の見込みが薄いもの |

出力フォーマット：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
Shira Notes 番組表リサーチ
対象日：{日付}　取得件数：{件数}件
━━━━━━━━━━━━━━━━━━━━━━━━━━

【高】{時間帯} ｜ {チャンネル} ｜ {番組名}
根拠：「{概要文からの引用}」

【中】{時間帯} ｜ {チャンネル} ｜ {番組名}
根拠：「{概要文からの引用}」

━━━━━━━━━━━━━━━━━━━━━━━━━━
候補 {件数}件（高{n} ／ 中{n} ／ 低{n}）
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

該当ゼロの優先度は省略してよい。候補が1件もない場合はその旨を伝える。

### Step 6. 次のアクション

候補の中から記事化するものが決まったら、`/shira-keyword-article`（テーマ記事）または該当番組の
専用リライトコマンドに進む。その際、この結果（概要文）だけを事実の根拠にせず、必ず一次情報を
追加で確認する。
