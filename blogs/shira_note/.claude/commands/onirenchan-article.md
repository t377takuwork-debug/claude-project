# 千鳥の鬼レンチャン 出演者の人物記事（サビだけカラオケ）

「千鳥の鬼レンチャン」のサビだけカラオケを観て「この歌っている人は誰？」と検索した人に読んでもらう、**人物ごとの記事**を作る手順。放送のたびに別の人物が出るので、**人物ごとに新しい記事（新しいURL）をWordPressへ追加する**。前の人物の記事は消さない。

**完了の定義**：`python tools/build_onirenchan.py …` で下書きを作り、検品が「ERROR 0件・新規WARN 0件」になること。

**しくみ**：人物ごとに変わる文章・数字だけを**入力ファイル（json）に書き**、プログラムが下書き（色付きの枠・構造化データ込み）を作る。**下書きを直接編集しない**（作り直すと消える）。直したいときは入力ファイルを直して作り直す。**もし下書きが直接直されていたら**、プログラムは上書きせずに止まって差分を見せる（`[停止]`）。その差分を先に入力ファイルへ反映し、作り直した内容が今の下書きと同じになってから作り直す（消えてよいときだけ `--force`）。

---

## ファイル

| ファイル | 役割 | 置き場 |
|---|---|---|
| `tools/build_onirenchan.py` | 下書きを作るプログラム。作ったあと検品まで自動で実行する | 残す |
| `tools/onirenchan/example_broadcast.json` | 放送回ファイルの見本。次の放送の入力は、これをコピーして書く（放送回の情報は人物で共通なのでコピーでよい） | 残す |
| `tools/onirenchan/broadcast_{放送日}.json` | 放送回ファイル。同じ放送の人物で使い回す | その放送の全員が完成したら削除 |
| `tools/onirenchan/{人物}.json` | 人物ファイル | 完成したら削除 |
| `drafts/draft_onirenchan_{人物}.txt` | できあがった下書き（WordPressへ貼る） | 完成したら削除 |

- **完成**＝結果を書き足してWordPressで公開し終えた時点。削除の前に、コミットしておく（履歴から取り出せる）
- `draft_onirenchan_` で始まる下書きは、文体（読点・ニュース調・句点・H3）も検品の**警告**になる（自動）
- 色の直し・配信ガイドの作りなど、**部品の直しはプログラム（`build_onirenchan.py`）の1か所だけ**でよい

## 手順

### 手順1. 放送回を調べる（放送回につき1回。人物で共通）

Claude in Chromeで次の2つを開く。**WebFetchは使えない**（公式サイトはドメインブロック、Xは有料の壁）。

**① 公式サイト** `https://www.fujitv.co.jp/oniren/`（主ソース）：`navigate` 1回＋`javascript_tool` 1回で、次回の放送日時・見どころの紹介文・挑戦者（五十音順・所属つき）・TVer（リアルタイムは固定の `tver.jp/live/cx`・見逃しはシリーズ）とFODのURLがすべて取れる（2026-09-26 実測）。

```js
await new Promise(r=>setTimeout(r,2500));
const t=document.body.innerText, h=document.documentElement.innerHTML;
({text:t.slice(t.indexOf('次回'), t.indexOf('スタッフ')),
  live:[...new Set(h.match(/tver\.jp\/live\/[A-Za-z0-9\/_-]+/g)||[])],
  series:[...new Set(h.match(/tver\.jp\/series\/[A-Za-z0-9]+/g)||[])],
  fod:[...new Set([...document.querySelectorAll('a')].map(a=>a.href).filter(u=>/fod\.fujitv\.co\.jp\/title\//.test(u)))]})
```

**② 公式X** `https://x.com/oni_renchan`：`navigate` 1回＋`javascript_tool` 1回で、直近の投稿の文面が取れる（2026-09-26 実測）。挑戦者ごとの予告の一言・見逃し配信の案内・「リベンジ参戦」などの文言を確かめるために使う。

```js
await new Promise(r=>setTimeout(r,4500));
[...document.querySelectorAll('article')].slice(0,12).map(a=>a.innerText.replace(/\n+/g,' ').slice(0,140))
```

- 最初は4件ほどしか出ない。挑戦者の予告が足りないときは、`window.scrollBy(0,2500)` を足して再実行する
- **「リベンジ参戦」「◯回目」などの文言に注意**（実測：SARIさんは「リベンジ参戦」で初参戦ではない）。2回目以降の人は、手順3の「2回目以降の出演」の型にする

**③ ユーザーに聞く**：どの人物の記事を作るか（全員か・除外する人はいるか）。**アイキャッチ画像と記事内画像のURL**（2つ）。

→ 放送回ファイルを書く（見本をコピー）。**atwiki・TVerは、ここでは開かない**（公式サイトに全部載っているため）。

### 手順2. 人物ごとに調べる

**事実は一次資料で確かめてから書く**（捏造禁止）。次は**書かない**：私生活・国籍・家族・恋愛・炎上などの噂、出どころのはっきりしない情報。年齢は「◯年◯月時点で◯歳」と時点を添える。

| 項目 | 取り方（回数の目安） |
|---|---|
| 所属・担当・生年月日・出身・身長・特技・趣味 | **所属事務所の公式プロフィール**をWebFetch（1回）。STARTO所属は `https://jr-official.starto.jp/s/jr/persons/{番号}`。事務所の公式プロフィールがない人（ものまね・外国人歌手など）は**Wikipedia**：`https://ja.wikipedia.org/w/index.php?search={名前}+鬼レンチャン&ns0=1&fulltext=1` で項目を探し（1回）、項目を読む（1回）。載っていない項目（所属・身長・血液型など）は**書かない**。**資料で数字が違えば公式の数字**（例：身長は公式175cm・Wikipedia173cm） |
| 最近の活動・今後の予定 | Yahoo!ニュース検索 `https://news.yahoo.co.jp/search?p={人物名}` をWebFetch（1回）。**検索語は名前だけ**（「SARI ZARD モノマネ」のように足すと0件になった）。あまり報じられていない人は0件でもよい。見出しに人物名がない記事も多い。本文を読むのは必要な1〜2本だけ |
| 鬼レンチャンの過去の成績（2回目以降の人だけ） | atwiki `https://w.atwiki.jp/onirensing/pages/10.html`（Chromeで）。**ファン作成で誤りがありうる**ので、成績は公式Xやニュースで裏取りする |

- **WebSearchは使わない**（無関係な質問サイトが混じる。日本国内の検索結果と差がある）
- **Grokは、放送後に「何曲目で何を歌ったか」の裏取りが要るときだけ**使う（放送前は使わない）

### 手順3. 型を確認する（人物ごとに1回だけ）

タイトル・見出し・メタ・スラッグは、**下の「型」に当てはめた案を1回だけ出して、ユーザーの「OK」を得る**。10案を出し直したり、分析を1から出したりしない（型は佐々木さんで確定済み）。

**タイトル**：`鬼レンチャン {人物名}は誰？{M/D}の挑戦者｜{所属や特徴の一言}`（前半はプログラムが作る。入力は後半 `title_tail` だけ。「鬼レンチャン {人物名}」の完全一致はタイトルが受け持つ）

**見出し**（プログラムが作る。②③は人物の角度に合わせて入力で変える）：
①鬼レンチャンに出演の{人物名}とは誰？（型。変えない）
②サビだけカラオケは何時から？挑戦者と見どころ【{M/D}】（初期値。`h2_when` で「リベンジ参戦の見どころ」のように変える）
③{人物名}は何レンチャン？歌った曲と結果【放送後に更新】（初期値。`h2_result` で変える）
④鬼レンチャンの見逃し配信はある？（型。変えない）
⑤よくある質問（H3：{人物名}は誰？・人物向けの質問・サビだけカラオケとは）
⑥【まとめ】

**見出し①の中の構成**（オーナー指定 2026-09-26）：**1〜2文 → プロフィールカード → 2〜3文**。カードは早めに置く。**文章はカードの繰り返しにせず、カードにない内容（きっかけ・経緯・今の活動など）で広げる役割**にする。「年齢」「経歴」「出身」の語は、カードの項目名に入れれば足りる（文で繰り返さない）

**メタ**：疑問文にしない。「{M/D}（曜）放送の『千鳥の鬼レンチャン』サビだけカラオケに初参戦する{所属}の{人物名}さん。{特徴}のプロフィールや見どころ・放送日時・見逃し配信をまとめました。」（90字前後）

**人物の種類による違い**
- グループ所属：2つ目のFAQ「◯◯のメンバーは？」
- ソロ・ものまね・外国人歌手など：2つ目のFAQを「◯◯さんの活動は？」など、その人に合う質問にする。`profile.group_label` は空にする
- 2回目以降の出演（例：SARIさん）：「初参戦」でなく「リベンジ参戦」など公式Xの文言を使い、2つ目のFAQを「鬼レンチャンは何回目の出演？」にする。過去の出演日はWikipediaとatwikiで日付が合うものを使い、**成績（何レンチャン）は公式サイトの「最高◯レンチャン」だけ**を書く（atwiki単独の情報は書かない）。**atwikiの「次回の1曲目」などは予告映像のネタバレなので使わない**

### 手順4. 人物ファイルを書いて、下書きを作る

1. **下の「入力ファイルの項目」を見て、`tools/onirenchan/{人物}.json` を一から書く**。**前の人物のファイルをコピーして名前だけ変えない**（使いまわし感の原因になる。見本は放送回ファイルだけ）
   - **先に、この人物の「角度」を1つ決める**：初参戦（デビュー・経歴の話題性）／リベンジ参戦（前回の課題→改善）／外国人歌手（得意分野）など。見出し②③・見どころ・まとめの言い回しを、この角度で組み立てる
   - 人物ごとに変える項目：`h2_when`・`h2_result`・`when_first`（放送日の文）・`vod_lead`・`vod_after`・`faq_lead`（空にすると省略）・`lead`（1〜2文の配列）
   - 同じ記事の中でも、同じ言い回しを3回以上繰り返さない（「3回目」「◯◯で知られるタレント」など）
2. 実行する（検品と**使いまわしチェック**まで自動）：
   ```
   python tools/build_onirenchan.py tools/onirenchan/broadcast_{放送日}.json tools/onirenchan/{人物}.json
   ```
3. ERROR・WARN・**「使いまわしの疑い」**（他の人物と、人名を除いて同じ文）が出たら、**入力ファイルを直して**作り直す。**すべて0件**になってから報告する。※使いまわしチェックは、同じ放送回の他の人物ファイルがあるあいだだけ効く

### 手順5. 放送後に結果を書き足す（未実地。最初の回で確かめて、この節を直す）

1. 公式Xとニュース記事で「何レンチャンだったか」「歌った曲」を確認する（atwikiは裏取りに使う）
2. 人物ファイルを直す：`result.paragraphs`（結果の文）・`result.suffix`（`""` にして「【放送後に更新】」を外す）・`guide.result_main`/`result_sub`（速報ガイドの結果欄）・`modified`（更新日時。Updateの日付と構造化データも自動で変わる）
3. **冒頭のリード文（`lead`）と、放送前の表現（「初参戦します」など）の扱いは、最初の放送後に決める**
4. 作り直して検品を通し、WordPressへ反映して公開する
5. 完了したら、下書き・人物ファイルをコミットしてから削除する（`git rm`）

## 入力ファイルの項目

**放送回ファイル**（`example_broadcast.json`）

| 項目 | 内容 |
|---|---|
| `date`・`weekday`・`start`・`end` | 放送日（`2026-09-27`）・曜日・開始と終了 |
| `channel`・`program` | フジテレビ・千鳥の鬼レンチャン |
| `official_url`・`x_url`・`x_handle` | 公式サイトと公式Xの情報 |
| `count_text` | 速報ガイドの挑戦者欄（「4名が発表済み」） |
| `challengers` | 挑戦者の配列。`key`（短い名前。人物ファイルの `name` と同じなら、カードを目立たせる）・`label`（カードの見出し。所属つき）・`note`（一言） |
| `challengers_note` | カード下の注記 |
| `update_promise` | 冒頭の「更新の約束」の1文 |
| `vod` | `lead`（案内の1文）・`realtime_url`（`https://tver.jp/live/cx`）・`series_url`・`fod_url`・`after`（配信ガイド後の1文） |
| `about_name` | 構造化データの `about` の名前 |

**人物ファイル**（見本はない。この表から書く）

| 項目 | 内容 |
|---|---|
| `name`・`file`・`slug` | 名前・下書きのファイル名の後半・URLスラッグ |
| `title_tail`・`meta`・`lead` | タイトルの後半・メタ（文字数と構造化データは自動）・冒頭の文（1文か、2文までの配列） |
| `published`・`modified` | 公開日時（ISO形式）・更新日時（省略すると公開日時と同じ） |
| `eyecatch`・`image_src`・`image_alt`・`image_id` | アイキャッチ・記事内画像・記事内画像のalt・記事内画像のWordPressの画像ID（省略可。あるとクラス `wp-image-ID` が付く） |
| `guide` | 速報ガイド：`challenger_sub`・`person_main`・`person_sub`・`result_main`・`result_sub` |
| `embed_html` / `embed_url` / `embed_position` | **任意**。ユーザーが埋め込みコード（Xなど）を渡したときだけ入れる（`embed_url` はXの投稿URLだけ）。ふだんは省略。位置は導入の文のあと・プロフィールカードの前（`embed_position` を `"h2"` にすると見出し①の直下） |
| `intro`・`after_profile` | 見出し①のプロフィールカードの前（1〜2文）・後（2〜3文）の段落（配列） |
| `profile` | `group_label`（カード右上。なければ空）・`rows`（`[項目, 値]` の配列）・`note`（出典の1文） |
| `when_first`・`when`・`after_challengers` | 見出し②の段落。`when_first` は放送日の文（省略すると「放送は◯月◯日（曜）の…で◯◯です。」）。`when`（空の配列でよい）は挑戦者カードの前・`after_challengers` は後。公式へのリンク文はプログラムが入れる |
| `h2_who`・`h2_when`・`h2_result` | 見出しの上書き（省略可。`h2_result` の `{suffix}` は【放送後に更新】に置き換わる）。公開済みの見出しを固定するときにも使う |
| `vod_lead`・`vod_after`・`faq_lead`・`more_info` | 見逃し配信の前後の文・FAQの前置き・「詳しい情報は」の文頭の上書き（省略可。`faq_lead` を空にすると前置きなし） |
| `result` | `suffix`（【放送後に更新】）・`paragraphs` |
| `faq` | `who`（「〜は誰？」の答え）・`q2`・`a2` |
| `matome` | まとめの段落（配列） |
| `keywords` | 構造化データのキーワード（省略すると自動） |
| `event_note`・`mentions` | 放送の説明に添える1文・構造化データの人物（`type` は Person / MusicGroup） |

## 記事の決まりごと

- **「さん」は本文の文章の中だけ**（オーナー指定）。見出し・カード・FAQの質問・画像のaltには付けない。段落・FAQの答え・まとめでは「佐々木大光さんは〜」と付ける。※プログラムが作る部分（見出し・カード・FAQの質問）は自動で付かない。入力の文章には自分で付ける
- **「誰」は5か所前後**：タイトル・見出し①・見出し①の最初の文・冒頭の1文・FAQ①。増やしすぎない
- 「年齢」「経歴」「身長」「出身」は、**プロフィールカードの項目名か文に、それぞれ1回は語として入れる**（載っていない項目は書かない）。人名と番組名は近くに置く
- **放送前は「歌は上手い？」を書かない**（事実がないため）。放送後に結果の欄へ足すときに入れるか決める
- 文体は `rewrite_common_rules.md` の16章（読点は少なく・人が話す口調・1段落1話・更新の約束は冒頭の1回だけ）に従う。検品が警告で知らせる
- **配信ガイド**：TVerのリアルタイム配信・TVer・FODの2列。**U-NEXTは入れない**（鬼レンチャンはU-NEXTで配信されていない。ユーザー確認済み）
- **色**：公式の番組ページに合わせた淡いピンク×青（`#d94c63`・`#2b4288`・`#2f51b7`・`#f9ede9`）。オールスター感謝祭の紺×金は使わない
- **ナビブロック「他の音楽番組もチェック」は入れない**。パンくずは「ホーム→記事→本記事」。`isLiveBroadcast` は false
