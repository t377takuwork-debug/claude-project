「千鳥の鬼レンチャン」のサビだけカラオケを観て「この歌っている人は誰？」と検索した人に読んでもらう、**人物ごとの記事**を作る手順。放送のたびに別の人物が出るので、**人物ごとに新しい記事（新しいURL）をWordPressへ追加する**。前の人物の記事は消さない。

始める前に完了を1行で決める：**「`drafts/draft_onirenchan_{人物slug}.txt` を保存し、`python tools/qa_draft.py` でERROR 0件・新規WARN 0件」**。

## 記事の考え方

- 検索する人の最初の疑問は「**この人は誰？**」。番組は「その人を知ったきっかけ」で、知りたいのは人物のほう。冒頭の答えは「◯◯のドラム担当」のように人物の紹介を先に置き、番組の情報（放送日時・見どころ）は補足にする
- 公開は**放送前**。放送前に「誰？」、放送後に「結果」を同じ記事へ書き足す
- **人物ごとに下書きを1本作る**（`draft_onirenchan_{人物slug}.txt`）。放送前に複数の人物を公開し、放送後に人物ごとの結果を書き足すため、同時に複数の下書きが残る（オーナー確定 2026-09-26）
- **結果を書き足して公開が終わった人物の下書きは削除する**（完成した記事はWordPressが正。削除前にコミットしておけば、履歴から取り出せる）
- **ひな形（見本）は消さない**。新しい人物は見本をコピーして作る

## 手順

### 手順1. 放送回と人物を確定する

1. 次回（または対象回）の放送日と挑戦者を調べる（下の「調べ方」）
2. **挑戦者のうち、どの人物の記事を作るかをユーザーに聞く**（全員か、検索されそうな人だけか）。ユーザーが除外した人物は作らない（9/27回はせいやさんを除く3人）
3. 人物ごとに手順2以降を回す

### 手順2. 人物を調べる

**プロフィールの事実は、公式サイトなど一次資料で確かめてから書く**（捏造禁止）。次は**書かない**：私生活・国籍・家族・恋愛・炎上などの噂、出どころのはっきりしない情報。

| 項目 | 使うところ |
|---|---|
| 所属（グループ・事務所）・担当・生年月日・出身・身長・特技・趣味 | 公式プロフィール（事務所の公式サイト）。**資料で数字が違うときは公式の数字**（例：佐々木さんの身長は公式175cm・Wikipediaは173cm） |
| 過去の活動・今後の予定 | Yahoo!ニュースの記事本文（WebFetch可） |
| 鬼レンチャンでの過去の成績（2回目以降の人） | atwiki（下記） |
| 今回の見どころ | 公式サイトの放送内容・公式Xの予告投稿 |

**年齢は「◯年◯月時点で◯歳」と時点を添える**（古くなるため）。

#### 顔が映っているXの投稿の候補を集める（プロフィールカードの上に埋め込む）

1. Claude in Chromeで、**番組公式X（@oni_renchan）**と、可能なら**本人・所属グループの公式X**のプロフィールページを開く。`article` 要素から、人物の名前が文面に入った投稿を探す
2. 各投稿のURL（`/status/数字`）と、画像・動画の表紙画像（`pbs.twimg.com/...`）を取り出す。表紙画像は `curl` でscratchpadに保存し、**Readで実際に見て「顔がはっきり映っているか」を確かめる**
3. **私（AI）は顔から「この人が誰か」を判断できない**。誰の写真かは、**投稿の文面に名前があること**を根拠にする。画像に複数人が映る場合は、その旨を添える
4. **候補を2〜3件、文面・映っている人数・投稿日と一緒にユーザーへ提示し、ユーザーが1件選ぶ**
5. 選ばれたら、記事に埋め込む（下の「記事の決まりごと」）

- **画像を保存してアップロードしたり、画像のURLをそのまま貼ったりしない**（著作権・肖像権のため）。必ずXの投稿の**埋め込み**にする
- **Instagramは使わない**（WordPress標準の埋め込みが使えず、埋め込みコードのスクリプトは保存時に消えるため。実地では未確認）

### 手順3. タイトル・見出し・メタ・スラッグをユーザーに提示して確認

`shira-keyword-article.md` の Step 3〜4 に沿う（分析→OK→タイトル10案→構成→確認）。**2人目以降は、1人目で確定した型を提示して「この形で」と確認するだけでよい**（10案から選び直さない）。

**タイトルの型**（佐々木さんで確定）：
`鬼レンチャン {人物名}は誰？{M/D}の挑戦者｜{所属や特徴の一言}`（例：KEY TO LITのドラム担当）

**見出しの型（H2 6本＋FAQ）**：

1. 鬼レンチャン {人物名}は誰？
2. サビだけカラオケは何時から？挑戦者と見どころ【{M/D}】
3. {人物名}は何レンチャン？歌った曲と結果【放送後に更新】
4. 鬼レンチャンの見逃し配信はある？
5. よくある質問（H3を3つ：①{人物名}は誰？②{グループ名}のメンバーは？③サビだけカラオケとはどんな企画？）
6. 【まとめ】

完全一致のH2は1つ目だけ。FAQのH3は「〜ですか？」にせず「〜？」で終える。

**メタディスクリプションは疑問文にしない**（オーナー指定）。「{M/D}（曜）放送の『千鳥の鬼レンチャン』サビだけカラオケに初参戦する{所属}の{人物名}さん。{特徴}のプロフィールや見どころ・放送日時・見逃し配信をまとめました。」の形（90字前後。「誰？」はタイトルに任せる）。

### キーワードの入れ方（2026-09-26 全体を数えて確認済み）

- **「誰」は5か所前後に分ける**：タイトル・H2①・H2①の最初の文（「鬼レンチャンを観て『この人は誰だろう』と」）・冒頭のリード文（「誰なのか」）・FAQ①。増やしすぎない
- 「年齢」「経歴」「身長」「出身」は**それぞれ1回は語として文に入れる**（「〜生まれで年齢は◯年◯月時点で◯歳です」「経歴は〜」）。カードだけに置かない
- 人名と番組名は近くに置く（「{人物名}さんは鬼レンチャンのサビだけカラオケに初参戦します」）
- 見出しは、人名がなくても企画名や「何時から」「見逃し」が入っていればよい
- **放送前は「歌は上手い？」を書かない**（事実がないため）。放送後に結果の欄へ足すときに入れるか決める

### 手順4. 下書きを作る

1. `template_parts/onirenchan_person_example.txt` を `drafts/draft_onirenchan_{人物slug}.txt` にコピーする
2. 下の「差し替える場所」の表に従って、人物と放送回の部分を差し替える（Edit）。**見本の人物名（佐々木大光）が残っていないか、最後にGrepで確かめる**（0件にする）
3. 保存したら、**確認を挟まず**そのまま検品を実行する（手順5）

**差し替える場所**

| 種類 | 差し替える場所 |
|---|---|
| **人物ごと** | タイトル・メタ・スラッグ・冒頭のリード文と速報ガイド（人物の行）・記事内画像とアイキャッチ画像・H2①の本文とプロフィールカード・見どころの本文・FAQの人物の質問2つ・まとめ・構造化データ（headline・description・keywords・mentions・performerのうち人物の分・FAQPage・パンくず・@idのスラッグ） |
| **放送回ごと** | 放送日時・挑戦者カード（公式の表記の順）・リアルタイム配信のURL（TVerの `live/simul/…` は回ごとに変わる）・見出しの【M/D】・構造化データの日時 |
| **ずっと同じ** | 見出しの並び・配色・サビだけカラオケのFAQ・見逃し配信のTVer・FODのURL・結果欄の骨組み・[nopc]ショートコードの位置 |

**人物の種類による差し替え**

- **グループ所属の人**：FAQ①「◯◯は誰？」（答えに所属とグループでの担当を入れる）＋FAQ②「◯◯のメンバーは？」（佐々木さんで確定）
- **ソロ・ものまね・外国人歌手など**（グループがない人）：FAQ①は「◯◯は誰？」のまま、FAQ②を「◯◯さんの活動は？」など、その人に合う質問に差し替える（メンバーの質問は使わない）
- **2回目以降の出演の人**：初参戦の記載を外し、「過去の成績」（atwikiの記録）を見どころに書く。事実は公式Xやニュース記事で裏取りする
- 特技・趣味などの行は、公式プロフィールにある項目だけを置く

### 手順5. 検品

```
python tools/qa_draft.py draft_onirenchan_{人物slug}.txt
```

ERROR 0件・新規WARN 0件になるまで直してから報告する。

## 記事の決まりごと（佐々木さんの回で確定）

- **Xの投稿の埋め込み**：H2①の「メンバー紹介の文」のあと・**プロフィールカードの直前**に置く。WordPressの埋め込みブロック（検品を通ることは確認済み）：
  ```
  <!-- wp:embed {"url":"https://twitter.com/{アカウント}/status/{数字}","type":"rich","providerNameSlug":"twitter","responsive":true,"className":""} -->
  <figure class="wp-block-embed is-type-rich is-provider-twitter wp-block-embed-twitter"><div class="wp-block-embed__wrapper">
  https://twitter.com/{アカウント}/status/{数字}
  </div></figure>
  <!-- /wp:embed -->
  ```
  URLは `twitter.com` の形にする（WordPress標準の対応が確実なため。`x.com` の形での表示は未実地）。**この形で表示されることは、2026-09-26の公開で確認済み**
- **人物の「さん」は本文の文章の中だけ**（オーナー指定 2026-09-26）。**見出し（H2・H3）・コード内（速報ガイド・プロフィール・挑戦者カード）・FAQの質問・画像のaltには付けない**。文章（段落・FAQの答え・まとめ）では「佐々木大光さんは〜」と付ける。タイトルとメタは、タイトルは付けず、メタは文章なので付けている
- **配信ガイド**：TVerのリアルタイム配信・TVer・FODの2列。**U-NEXTは入れない**（「千鳥の鬼レンチャン」はU-NEXTで配信されていない。ユーザー確認済み。2026-09-26）。`template_parts/haishin_guide.html` のU-NEXTの列は使わない
- **色**：公式の番組ページに合わせる。差し色 `#d94c63`・青 `#2b4288`（濃）／`#2f51b7`・背景の淡いピンク `#f9ede9`。オールスター感謝祭の紺×金は使わない
- **ナビブロック「他の音楽番組もチェック」は入れない**
- **アイキャッチ画像と記事内画像は別のURL**。立ち上げのとき2つとも聞く
- **カテゴリは未確定**。構造化データのパンくずは「ホーム→記事→本記事」の簡易形（カテゴリが決まったら差し替える）
- `isLiveBroadcast` は false（収録番組。生放送ではない前提）
- 更新の約束は冒頭の締め文の1回だけ（16-3）
