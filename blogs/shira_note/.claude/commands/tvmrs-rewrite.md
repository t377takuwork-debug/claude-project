## リライト手順

### 1. ファイル準備

全面リライトなら `drafts/draft_tvmrs.txt` を全文Read 1回。加えて `template_new_article_skeleton.txt` は参照不要（このdraftが実体テンプレート）。

**放送後フローで資料②が来た場合**：上書き前の「放送レポート」パネル（`aria-label="テレビ×ミセス放送アーカイブ"`）の中身を**退避データ**として保持する。ここは「前々回」のデータで、資料②で上書きされる。手順11で「過去の放送内容一覧」に追加するのはこの退避データ（資料②ではない）。

### 2. タイトル・メタディスクリプション

**タイトル形式（この番組の確定型・2026-09-01ユーザー合意）**
```
テレビ×ミセス タイムテーブル【M月D日】出演順や出演者、放送は何時から？
```
- 「テレビ×ミセス タイムテーブル」を先頭・隣接で固定（主要KW／3章）。放送日は「M月D日」、【2026】ブラケット・数値焼き込みなし
- **入れない**：「コーナー進行」（長い）／「リアルタイム更新」「速報」（訴求語・不要）／文中の単独「いつ」（【M月D日】と同枠にあると矛盾して見える）
- 「放送は何時から？」の疑問形は【M月D日】と両立可（"時刻"の質問で"日付"と役割が別）。**中黒の名詞羅列（出演順・出演者・出演時間）より、読める一文にする**
- 40字以内。`headline`（JSON-LD）と一字一句一致

**メタディスクリプション（100〜120字）**
```
テレビ×ミセス（M月D日・TBS）タイムテーブルを速報更新！{今回の目玉：歌唱曲/コラボ/コーナー}のコーナー進行・出演順・出演時間の目安を随時追記します。
```
- 「出演順」を必ず含める（3章）。「タイムテーブル」を含める。前回と同じ文言にしない（10-1）
- **確定後の文字列を手順14のJSON-LD `description` に丸ごとコピー**

### 2b. リード文（`[nopc][title][/nopc]` 直後の1文・aside直前）

冒頭にコード（aside）が入るため**1段落・1文**に抑える。ハイプ・CTA・「速報」「リアルタイム更新」・単独「〜は？」の疑問断片は入れない。**この記事の守備範囲を述べる一文**にする（2026-09-01ユーザー確定型）。

```
次回放送の「テレビ×ミセス」がいつ放送されるのか、出演者やタイムテーブル、進行の順番などをまとめています。
```

- 4クエリ（`いつ放送` / `出演者` / `タイムテーブル` / `進行の順番＝順番`）を**自然な名詞の並び**でこの1文に織り込む（密度調整はしない・下記「キーワード配置」参照）
- 具体的な日付・時刻は直後のasideが持つのでリードには書かない

汎用文（「楽しみですね」）は使わず、今回固有の歌唱曲・コーナー名を主語にする。
