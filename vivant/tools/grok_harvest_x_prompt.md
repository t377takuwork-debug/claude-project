# Grok X反響ハーベストプロンプト（vivant 最新回リサーチ用）

`/vivant-episode-update` Step 1 のX反響収集で使う。**Grok（grok.com）を「ファスト」モードで**実行する（エキスパートはX Premiumだと週1で上限に当たるため常用しない）。

## 使い方
1. grok.com で新規チャット。モードが「ファスト」であることを確認（「モデル選択」ボタンで切替）。
2. 下の本文の `{対象回}` `{シーズン内話数}` `{放送日}` `{放送日+4}` `{ハッシュタグ}` `{第N話の主な出来事}` を差し替えて投入。
   - `{放送日}` `{放送日+4}` は `YYYY-MM-DD` 形式。`{放送日+4}` は放送日の4日後（例：放送9/6 → 9/10）。
   - `{ハッシュタグ}` は `#VIVANT #VIVANT考察 #VIVANTep17` のように話数を付ける。
   - `{第N話の主な出来事}` は放送直後にWebSearchで拾った3〜6行の箇条書き（Grokに検索の手がかりを与える）。話数固有の人名・組織名・数字・セリフ断片を入れる。
   - 検索クエリ8本のキーワード（テーマ語）も、その回で実際に出た固有名詞へ差し替える。
3. 出力をそのまま `vivant/raw_grok_x_ep[N].md` として保存、またはチャットへ貼付。
4. Chrome自動操作で回す場合：grok.comは screenshot/read_page/get_page_text がタイムアウトするため `javascript_tool` のみ使用。投入は ProseMirror へ `ClipboardEvent('paste')` 合成、送信は `[data-testid="chat-submit"]` をJSクリック、抽出は `window.__var` 格納→1500字スライスを並列取得。
