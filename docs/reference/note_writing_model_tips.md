# Sonnet 5.5 でNote記事を書くときの補強（2026-10-01）

Opus 5.5の良さを、Sonnet 5.5のmedium／highでも出すための指示と修正ポイント。UYAnote の記事づくり（UYA.）と `/note-article`（s4lv等）の本文生成で使う。

**このファイルの確かさ**：検証したのはUYA.の1テーマ（「noteはこだわりすぎて1本に丸1日」）を、モデルごとに1回ずつ書かせた結果だけ。「観察できたこと」と「まだ試していない仮説」を分けて書く。元の結果は `uya/articles/sonnet5_vs_55_quality_test_results_1001.md`、Sonnet 5.5のリサーチは `uya/articles/sonnet55_research_and_s4lv_x_draft_1002.md`。

**他のアカウントで使うとき**：ここに書くのは、文章の流れ・具体さ・字数・事実の範囲といった「作りの部分」の補強。文体や口癖は、各アカウントの文体ルール（s4lvなら`note_article_checklist.md`、UYA.なら`examples_essay.md`）が優先する。

---

## 1. 観察できた違い（Opus 5.5・high と Sonnet 5.5）

| 観点 | Opus 5.5・high | Sonnet 5.5（medium／high） |
|---|---|---|
| 話のつながり | 「AIの文章が悪いわけじゃない。ただ、私が書いた文に見えなくて」のように、前の文を受けて理由や対比でつないでいる | mediumは、段落ごとに「自問して終わる」形がくり返され、流れが平らになる傾向。highは改善する |
| 具体さ | 材料の事実を、読み手が思い浮かべやすい形に言い換えている（語尾が「強く聞こえたり、冷たく聞こえたり、他人ごとに聞こえたり」） | 事実をそのまま述べる文が多く、言い換えが少ない |
| 終わり方 | 「読む人のことを考えてる時間が、長いだけかもしれない」で、読み終えた人が少し楽になる形にまとまっている | highは近い形。mediumは自分の気持ちの確認で終わりがち |
| 弱点（共通の注意） | 文末の約35%が「〜て。」。材料にない小さな感情を足す（「白紙から書き始めるのもそれはそれで重い」） | 同じく材料にない感情を足す（程度は軽い）。短い投稿では字数が指示よりわずかに短くなることがある |

外部の情報（Every社・2026-09-29）：Sonnet 5.5は、長い下書きだと要点が埋もれ、話のつなぎが弱くなる。一方、手直し作業は強い。

## 2. 補強の指示（本文生成の依頼文に足す・観察に基づくもの）

### A. 長文を一度に出させない
1. 構成案（H2）が合意できたら、**各H2について「この段落の要点（1行）」と「前の段落から何でつなぐか（理由／対比／言い直し のどれか）」を先に書かせる**
2. その上で本文を書かせる。長い記事は、H2ひとつずつ書かせて確認してもよい
（根拠：Every社の報告と、mediumの初稿で段落の形がくり返された観察）

### B. 抽象語は、材料の範囲で具体に言い換える
- やってよい：材料にある事実を、読み手が思い浮かべやすい形に説明する（状況の細部・感じ方の言い換え）
- やらない：**新しい出来事・数字・材料にない気持ちを足す**（例：材料にない「〜と感じる日もある」）
- 迷ったら、足さずに材料のままの言い方に戻す

### C. 終わり方
- 読み終えた人が「少し楽になる／自分もそうかもしれない」と思える一文で終える
- ただし教訓・格言・「〜が大切です」の形にしない

### D. 文末の偏りをほどく
- 「〜て。」「〜で。」で終わる文が、全体の3割を超えないようにする（目安。Opusは35%、Sonnet 5.5は約20%）
- 超えたら、一部を言い切り・体言止め・「〜かも。」などに変える

### E. 字数は最後に数える
- 保存前に `qa_article.py` の「本文文字数」で指示の字数に入っているか確認する（今回のSonnet 5は指示の1,800字に対して623字だった）
- 足りなければ、足りない箇所だけ指定して書き足す。全体を書き直さない

---

## 3. 手直しの1回（まだ試していない仮説）

Sonnet 5.5は手直し作業が強いと報告されているので、初稿を書かせたあと、**つなぎ・具体さ・文末だけを直す手直しを1回**入れると、Opusの良さに近づく可能性がある。まだ試していない。

手直しの依頼文（例）：
```
この記事を、内容と事実は変えずに、次の3点だけ直してください。
1. 段落のつながり：前の段落を受けて、理由か対比でつながっているか見直す
2. 抽象的な言い方：材料の範囲で、読み手が思い浮かべやすい言い方にする（新しい出来事や気持ちは足さない）
3. 文末：「〜て。」「〜で。」が続いている所を、言い切りや体言止めに変える
直した箇所の一覧と、変えなかった理由が分かる所は、最後に書いてください。
```

## 4. 努力レベルの目安

- 基本は **medium**（ルート`CLAUDE.md`の決まりどおり。変更なし）
- 初稿の声が薄い、つながりが弱いと感じたら、**同じ指示をhighで1回だけ書き直す**（今回のUYA.の課題では、highのほうが声が出て、指示の字数も守れた）
- **maxは使わない**（費用と時間が跳ねる。文章では品質が上がるが、xhighまでで足りる、という報告が多い）
- Opus 5.5は、判断が分かれる企画・構成の作業に取っておく（Note本文では、highどうしの差は小さかった）
