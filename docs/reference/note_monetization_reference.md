## Part 1：note.com プラットフォーム一次データ

### 収益規模（【公式一次】note 11周年リリース・2025-04）

| 指標 | 数値 |
|---|---|
| 収益化した累計クリエイター | 20万人以上 |
| 直近1年のユーザー→クリエイター流通総額 | 170億円超 |
| 売上トップ1,000クリエイターの年間平均売上（2024年度） | 1,332万円 |
| 1ユーザーあたり月間平均支払い額 | 2,696円 |
| 会員登録者数 / 投稿数 / コンテンツ購入経験ユーザー（累計） | 938万人 / 5,598万件 / 438万人 |
| Google との資本業務提携 | あり（AI活用サービス開発） |

**示唆**：母集団は大きいが、トップ1,000の年間平均が1,332万円。s4lv が狙うのは「一発の大ヒット」ではなく「複数記事＋メンバーシップの積み上げ」。1ユーザー月2,696円という定着した消費行動＝**単発高額よりも継続課金（メンバーシップ）の方が市場の財布に合っている可能性**。

### 価格・売れ方の実勢（【公式一次】note「約30万件の有料記事を分析」）

| コンテンツ種別 | 平均価格 |
|---|---|
| 実用ノウハウ系 | 1,842円 |
| 読み物系（エッセイ等） | 983円 |

- 設定可能範囲：無料会員 100〜50,000円／有料会員 100〜100,000円
- **有料記事の価格は公開後も変更可**（反応を見て調整できる）。**サブスクの価格は変更不可**（初期設定を慎重に）
- **文字数と売上の相関係数はほぼゼロ（-0.023〜0.011）**。長さは売上に効かない
- 売上成長率：メンバーシップ 前年同月比 +81.3%（購入件数 +86.3%／売上発生クリエイター数 +100.5%）、有料記事 +26.8%

**示唆**：s4lv の核記事 ¥4,980 は実用ノウハウ系平均（1,842円）の約2.7倍。プレミアム位置づけとして意図的なら妥当だが、「なぜ平均の2.7倍を払うのか」を無料部分で証明できているかを毎回問う。**分量を増やす方向の改善は売上根拠が薄い**（相関ゼロ）。メンバーシップの伸びは有料記事の約3倍。

### 売れているテーマ（【公式一次】同上・急上昇カテゴリ）

- テクノロジー・AI活用
- SNS運用
- 複業・在宅ワーク（収入アップ関連）
- 育児・教育（課題解決ノウハウ）

**新規参入者でも上位に入れる**：育児カテゴリのメンバーシップでは売上トップ10のうち7人が1年以内の新規参入。成長カテゴリでは先行者優位が弱い。

**示唆**：s4lv の「個人ブログ×SEO×AI実装」は AI活用・SNS運用・複業の交差点。カテゴリ選定は外していない。

### note編集部・公式「有料コンテンツを売る6つのヒント」（【公式一次】note/notemag）

1. **記事の価値を無料部分で明示** — 何が得られるか／著者の経歴・体験／対象読者と具体的利益。エッセイは冒頭で試し読み
2. **無料部分だけで読み応えを確保** — 背景知識は無料、実践方法は有料の構成。無料箇所だけで完結した価値を出す
3. **公開後もアップデート** — 加筆修正／購入者への更新通知／未完成公開→随時更新の販売も可
4. **読者の反響を記事冒頭に掲載** — 本の帯の推薦文と同じ効果
5. **価格を柔軟に調整** — 有料記事は変更可なので反応を見て動かす（サブスクは不可）
6. **サブスク購読者を増やす** — 初月無料で80%以上が翌月継続（2023-08時点）／早期参加割引／ターゲット別の複数プラン／加入特典（PDF・プロンプト・コミュニティ招待）

## Part 2：3レンズの思考モデル

### ① 需要・ポジショニング担当 — アンカー：Amy Hoy「Sales Safari」＋ Philip Kotler「STP」

**核となる問い**：この痛みに金は流れているか。競合有料記事と何が違うか。

**Amy Hoy / Sales Safari（需要の掘り方）【手法】**
- インタビューやアンケートではなく、ターゲットが集まる場所（フォーラム・SNS・レビュー・質問サイト）で、**本人が見られていると気づいていない状態の発言を観察**する（"net ethnography"）
- 記録は5分類：Rough Notes（雑多な文脈）／Pains（痛み・引用と日時つき）／Worldview（口に出さない世界観「〇〇はこうあるべき」）／Jargon（本人たちが使う語彙）／Recommendations（読者どうしが薦め合う解決策）
- **「分析の多くは"言われていないこと"にある」**。表面の痛みと本当の痛みは違う（例：「高すぎる」という不満の本質が「金額が読めない＝予測不能」だった。別の問題・別の解決策）
- 使い方：Pains→切り口・記事テーマ／Worldview→デモグラでなく信条でターゲティング／Jargon→読者の言葉でタイトル・コピーを書く／Recommendations→競合の代替手段を把握
- 本気でやると30時間以上。素人は訓練するまで重要なシグナルを取りこぼす

**Philip Kotler / STP（理論の骨格）【一般論】**
- Segmentation → Targeting → Positioning。「なんとなく」「売れそう」は却下する
- 適用：セグメントを絞りきれているか（notekaigi Step 0 で読んだ対象アカウントの persona ファイル）。ポジショニングは競合記事に対して理論的に成立するか

**このレンズが会議で必ず確認すること**
- そのテーマは対象アカウントの persona ファイルが定義するペルソナの痛みに直結しているか
- 痛みは"表面"で止まっていないか。読者の実際の言葉（Jargon）を1つ以上挙げられるか
- 競合の同テーマ記事を1本以上具体的に挙げ、対象アカウントの差分を1文で言えるか

### ② 成約・価格・導線担当 — アンカー：Nathan Barry「Authority」＋ Justin Welsh

**核となる問い**：タイトル・強ワード・価格帯・ペイウォール位置・CTA は成約に向いているか。

**Nathan Barry / Authority（有料デジタルライティングの型）【手法】【実績公開】**
実績：デザイン/マーケの3冊で50万ドル超。1,000人未満のメールリストで初日1.2万ドル（App Design Handbook）。著書 "Authority" は15,000部超・読者が書籍で500万ドル超を売上。Kit（旧ConvertKit）創業者で経歴は検証可能。
- **「知っていることを全部教える」** — 教えること自体が専門家の地位を作る。トップ専門家である必要はない
- **3層価格**：例 $39（本のみ）／$79（本＋動画）／$169（フルパッケージ）。**同じ内容を別メディア（PDF・音声・動画・テンプレ）で提供して上位ティアを正当化**する。テキスト追加だけでは高価格の理由にならない
- ローンチ前：ランディングページで opt-in を取り需要測定／1,000字級の記事を3本／メールリストに週1〜隔週配信／関連メディアへのゲスト投稿7〜10本
- ローンチ：前日に予告 → 当日ブログ記事＋朝メール → 購入者にシェア依頼
- **ローンチ後の売上の谷は必ず来る**。CTA付きコンテンツを作り続け、教育＋ソフト/ハードセルを混ぜた自動メール列を組む
- 価格は書籍の相場でなく提供価値で決める／値引きは6ヶ月待つ（初期購入者を裏切らない）／新版は既存客に50%オフ／返金は寛容に（率5%超で初めて心配する）

**Justin Welsh（個人・オーディエンス→有料の導線）【実績公開】**
実績：約5年9ヶ月で総額1,000万ドル、年商約415万ドル、粗利約86%、従業員0（パートVA1名）、広告費ゼロ・100%オーガニック。月次で売上内訳を公開。
- 構造：1つのSNS（LinkedIn）＋無料ニュースレター（25万人超）→ 知識を**低単価（約$150）でスケールする商品**に productize（講座：年約8,667本）＋テンプレのサブスク＋スポンサー（売上の5〜7%）
- 学び：入口は1媒体に集中。無料で信頼を貯め、有料は「低単価×高回転×自動化」。数字を公開して信頼を担保する

**このレンズが会議で必ず確認すること**
- タイトルに読者の検索語・痛みの言葉が入っているか（対象アカウントの cheatsheet ／ ネタ台帳の語彙と整合）
- ペイウォール位置：無料部分だけで完結した価値があるか（note公式ヒント2）。有料の目玉を無料側で明かしていないか
- 価格の根拠：note実勢（実用ノウハウ系平均1,842円・読み物系983円）に対する乖離を、内容・フォーマット（3層化・テンプレ/動画付与の余地含む）で説明できるか
- 公開後の谷対策（SNS投稿・更新通知・反響掲載・自動導線）が設計に入っているか
- 単発有料記事とメンバーシップ、どちらがこのテーマの財布に合うか（市場はメンバーシップが+81%）

### ③ CEO — 意思決定・アイデンティティ担当 — アンカー：Adam Enfroy「一人メディア企業のCEO」

**核となる問い**：対象アカウントのコンセプト／アイデンティティと整合するか。後戻りリスクをどう見るか。何を優先するか。

- 思考モデル全文は `docs/reference/blog_monetize_personas.md` の Adam Enfroy 節を参照（利益から逆算・自分を小規模メディア企業のCEOとして経営・コンテンツは手段）
- 役割：Round 1 の対立を整理し、**1つの決定に落とす**。「どちらが正しいか」でなく「この状況で何を優先するか」を明示する
- 裁定基準：
  - アイデンティティ整合（notekaigi Step 0 で読んだコンセプト／identity ファイル）。数字の誇示・経歴ドラマ・情報商材的な煽りに寄っていないか（アカウントごとの禁止事項に従う）
  - 不可逆性（価格アンカー・実名や実績の開示範囲・プロフィール・目標数値は簡単に戻せない）
  - この決定は仕組み化・レバレッジを生むか（旧「池田朋弘流AIエージェント」視点をここに吸収）
- 決定は必ず `[更新]` で運用ファイルに配線する（memory だけに残すと次のバッチ生成で消化されず空振りする）
