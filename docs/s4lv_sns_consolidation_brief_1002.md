## 1 目的（一言）
s4lvのXの運用はほぼ確立した。**Threadsを同じ仕組みで整理して確立させる。** そのために、s4lv関連の文書を棚卸しして、要らないもの・重複・食い違い・トークンの無駄をなくし、**オーナーの最新の意図だけが正として残る状態**にする。

## 2 オーナーの意図（確認済み・2026-10-02）
1. Xの運用は確立済み。Xを基準に、Threadsを同じ仕組み（手順・声・材料・審査・保存）で整える
2. ネタの確保（`/neta-research` の外部リサーチと `/journal` の音声ジャーナル）は、X・Threadsで共通。UYA.とは**材料の置き場だけ**共通で、声・口調は共通にしない（UYA.は独立したアカウント）。同じ素材を同じ週に使わない決まりは残す
3. Xで調整した語尾・トーン・口調・温度感は、Threadsにもそのまま反映する。Threads独自の文体は持たせない
4. 反響の狙いとアルゴリズムは、XとThreadsで別物。役割に合った投稿にする（Xは `reference/x_algorithm_2026.md`、Threadsは `reference/threads_algorithm_2026.md`）
5. s4lv関連の全ファイルを棚卸しする。削るもの：要らないファイル、重複した指示、不要な指示、食い違い、毎回読んで無駄にトークンを使う指示。構成をなめらかにする
6. 置き換えた旧い決まりは、注意書きで残さず**削除**する（履歴は git に残る）。オーナーが採用した判断は蒸し返さない
7. **今後のオーナーの指摘も、学習して反映される仕組みにする。** 指摘のたびに、食い違う旧い記述が削除・更新され、食い違いが再発しないこと（下の「5 仕組みの設計」）
