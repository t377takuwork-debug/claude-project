## 0. 審査しないこと（drift防止・最初に読む）

以下は**このルーブリックの対象外**。指摘に含めない。

- **文体のセンス・訴求力**：比喩の強弱、情緒、叙情、「体温」、フックが"強い"かどうかの主観評価
- **旧確定構造への適合**：「エグい比喩 → 記憶のゆらぎ（あれは冬だったかな）→ 静かな真理」／情緒サンドイッチ／「弱さの開示 → 矜持 → 属性を絞った問いかけ」——これらの型に沿っているかは**審査しない**（2026-09-06にこの型が旧文体へ引き戻す原因になったため、審査基準から外す）
- **100点満点の採点**：スコアは付けない。PASS/FAIL と指摘表のみ

このルーブリックが見るのは「**根拠・開示・初心者可読性・名前のついたAI臭さパターン・投稿群整合**」だけ。それ以外で指摘を作らない。

## 1. 判定の枠組み

| 重大度 | 意味 | 提案可否 |
|---|---|---|
| **BLOCK** | 出せない。捏造・開示違反・機械ERROR・根拠のない主張 | 不可。修正必須 |
| **FIX** | 出せるが質を落としている。可読性・AI臭さパターンに明確に反する | 不可。修正してから（最大2巡） |
| **NOTE** | 判断が分かれる・運用上の注意・次回への示唆 | 可。指摘を添えて提案 |

- **PASS ＝ BLOCK 0件 かつ FIX 0件**。NOTE は残ってよい
- FAIL → 司令塔が指摘に沿って修正し再審査。**同じ指摘への修正は2巡まで**。2巡後に残る FIX は、現状・試したこと・残る理由を添えてユーザー判断に回す（黙って通さない・黙って落とし続けない）
- 機械QA（`qa_post.py`）で ERROR が出たら即 FAIL。LLM審査はしない
- WARN は審査員が1件ずつ「要修正（FIX）／許容（NOTE）」に振り分ける。許容には理由を書く

## 2. 審査員の態度（忖度禁止）

- 褒めから入らない。「全体的に良い」で済ませない
- すべての指摘に**投稿番号＋行の引用**を付ける。引用できない指摘は出さない
- 上記「0. 審査しないこと」に触れる指摘は出さない。根拠は必ず本ルーブリックの項目＋正ファイルの節を示す
- 見つからなければ「該当なし」と書く。無理に指摘を作らない
- **本文は書き換えない**。直し方は1文で示す（全文書き直し案は出さない＝司令塔の仕事）

## 4. 出力フォーマット（固定・この形以外で返さない）

```
## 審査結果: PASS
（または）
## 審査結果: FAIL（BLOCK n件／FIX n件／NOTE n件）

対象: <パス>　媒体: <x|threads>　投稿数: <n>本
機械QA: ERROR <n> / WARN <n>（WARNの振り分け: FIX <n> / NOTE <n>）

| # | 重大度 | 区分 | 投稿・行 | 指摘（本文引用） | 直し方（1文） | 根拠 |
|---|---|---|---|---|---|---|
| 1 | BLOCK | C | ②L3 | 「古い数字や日付を新しいものに直してもらう」 | 記事種別が透けるので「古くなった記述を新しい情報に差し替える」に一般化 | 本ルーブリックC／x_neta_daicho A1開示注意 |
| 2 | FIX | D | ①L1 | 「YMYLかどうかを先に判定します」 | 1行目を読者の状況で開き、専門語は2文目以降で言い換える | 本ルーブリックD／読者の入口 |
（BLOCK→FIX→NOTE の順・同重大度内は投稿番号順）

### 総評（3行以内）
- 一番効く修正: #n（理由1文）
- 良い点: 1つだけ、投稿・行付き（無ければ「特記なし」）
- 次回への示唆: 1文（無ければ省略）
```

- 見出し行の件数は**表の行数**と一致させる（同種の指摘は1行にまとめ、行欄に該当箇所を列挙）
- 指摘が0件の区分は表に出さない。全区分0件なら表を省略し「指摘なし」と書く
- 2巡目以降は「前回#nの対応: 解消／未解消（理由）」を表の前に1行ずつ書く

## 5. 更新ルール

- 項目の追加・重大度の変更は本ファイルを先に直し、`sns-ai-reviewer.md` は参照するだけ（手順を再掲しない）
- 定義そのものの変更は `x_neta_daicho.md` / `feedback_s4lv_x_writing_style.md` 等の正へ。本ファイルには書かない
- 審査で「ルーブリックにないが明らかにおかしい」が出たら、NOTE として指摘し、本ファイルへの追加を司令塔経由でユーザーに提案する（審査員が勝手に基準を増やさない）
- **「0. 審査しないこと」に項目を足す・外すのは `/notekaigi` 案件**（審査員も司令塔も単独で変えない）
