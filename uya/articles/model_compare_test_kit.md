# Sonnet 5 と Sonnet 5.5 の読み比べキット（Note記事・X・スレッズ）

これは比べるための試験用のファイル。記事や投稿として公開するものではない（公開する場合は各スキルの手順に戻す）。
作成日：2026-10-01（同日、Opusとの比較だと読み違えていたものを、Sonnet 5とSonnet 5.5の比較に作り直した）

## 0. 比べ方の基本

- **比べる相手**：Sonnet 5 と Sonnet 5.5。ふだんの運用と同じ努力レベル（Note記事・X・スレッズとも **medium**。`CLAUDE.md`の決まりどおり）で、**2つのモデルに同じ条件**を渡す
- **おまけの1本**：課題Aだけ、Sonnet 5.5をhighでも1本書かせる（mediumで不自然だったとき、highで直るかを見るため。2026-10-01に追加）
- **別々の新しい会話**で貼る（前の会話を引きずらない）
- 貼る前に、画面のモデル名が「Sonnet 5」「Sonnet 5.5」のどちらか確認する（5.5のつもりで5を使っていた例がある）
- **書き手を隠して読む**：出てきた文章を別ファイルに貼り、モデル名を消してから採点する
- 出るまでの時間と、使った量（画面に出れば）をメモする
- 参考：Opus 5.5を1本だけ足したければ、同じ文面を貼って基準にできる（必須ではない）

|---|---|---|

### 材料（この事実の範囲だけ使う。ここにない体験・数字は書かせない）
- noteの記事づくりにAI（Grokなど）を取り入れている
- ただし、自分が意図した語尾やニュアンスにならず、手直しにかなり時間がかかる
- 性格が完璧主義寄りで、直し始めると止まらない
- 有料記事を買ってくれた人に生かしてもらいたいと思うので、完成間際でも分かりにくい所を見つけると潰し続けてしまう
- AIを使っても、この「潰し続ける」は変わらない
- ブログより難しいと感じる。こだわりが強すぎて、1本に丸1日かかる
- noteのアカウントは3〜4つ持っている（出してよい事実。出したくなければ消す）
- 金額・売上・PV・記事名・ほかのアカウントとの関係は書かない

## 2. 課題B：Xの投稿3本（s4lv・努力レベル medium）

### 貼る文面
```
あなたは、X（旧Twitter）の投稿を書く手伝いをします。書き手は「s4lv」という、10年以上テレビ・エンタメ系のトレンドブログを運営してきた人です。読者は、ブログを続けるか迷っている初心者〜中級者です。

【投稿は3本。1日分（朝7:30／昼12:15／夜20:45）】
一番強い1本を夜に置いてください。

【使ってよい事実（これ以外の体験・数字・固有名詞は書かない）】
ネタ1（夜）：検索で上位を狙うときの、キーワードの言葉の数の扱い
・1語は、個人ではまず無理なので狙わない
・2語は、強い競合がいなければ普通に狙う。強い競合がいても、サイトの作りから整えれば1位を取れることがある
・3語4語の細かく絞った言葉が、主な戦場
・狙っていた2語に強い大手メディアや公式サイトが居座ったら、細かい言葉へ1回だけずらす。ずらせなければその記事は畳む
・昔は負けを認めたくなくて、リライトを重ねて時間だけ失った

ネタ2（朝）：量産型に見られない書き方
・更新の案内などの決まった一文を、前回と同じ言い回しで書かない
・同じ文を1つの記事で3回以上くり返さない
・「編集部」など組織を装う主語を使わず「私」で書く
・リライトした記事を並べて調べたら、文面の7割が同じだった（数字は「7割」まで）

ネタ3（昼）：記事のタイトルの決め方（AI活用）
・タイトル案は勘で選ばず、5項目の採点表で点数を出してから決める
・5項目＝実際に測った数字／感情のトリガー／今の話かどうか／自分にもできそうと思えるか／得られるもの
・採点せずに「良さそう」で出すと、あとから基準がぶれる

【文体】
・初心者にも分かる平易さを最優先。カタカナ語・専門用語は使わない
・「大手」と書くときは「大手メディア」「公式サイト」など具体的にする
・句点ごとに改行。話題の切れ目に空行を1つ。読点は1文に2つまで
・キーになる語句は「」で囲む
・締めは、断言か観察で終える。疑問符で締めない。教訓・格言で終えない
・「〜ですね」「〜と思います」「〜が大切です」「まとめると」は使わない
・文末を「〜ました。」で終える本は2本以内。3本の1行目の入り方は変える
・URL・ハッシュタグは入れない。実績の大きい数字は出さない

【出力】
本文3本と、それぞれの投稿時刻を書いてください。
```

## 3. 課題C：スレッズの投稿2本（UYA.・努力レベル medium）

【投稿は2本】

【使ってよい事実（これ以外の体験・数字・固有名詞は書かない）】

・収入は月によって振れ幅が大きい（金額は書かない）

・1行目は、現場の具体か事実から入る。指摘や説教では始めない
・問いかけは、2本のうち1本以下。読点は少なく
・「〜と思います」「〜が大切です」「まとめると」は使わない
・煽らない。稼げる・すぐできる、と言わない

## 6. 結果の見方（先に決めておく）

- 5.5のほうが、手直しが少なく、事実の範囲も守れている → 既定を5.5へ
- 5と差がない → 速さと費用の違いだけで選ぶ
- 5.5のほうが不自然・冗長・事実の逸脱が多い → その課題（Note／X／スレッズ）だけ5のまま、または努力レベルを上げて再比較
- 課題ごとに結果が割れたら、課題ごとに使い分ける
- 課題A：A-2（5.5のmedium）がA-1より自然で手直しが少ない → Note本文も5.5のmediumでよい。A-2が不自然でA-3（high）で直る → Note本文だけhigh。A-3でも足りない → 書き下ろしはほかのモデル（Opus等）との比較を足す
