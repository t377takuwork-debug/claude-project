# 価格・種別の基準(UYA.の決まり。出どころは `0_社長室/UYA設定/project_uya_positioning.md` と `参考資料/note_monetization_reference.md`)

- 種別が指定されていなければ、**このnoteアカウント自体の読者がまだついていない間は無料記事を推奨する**(体験談は無料で信頼を貯める)
- 有料にするとき：実用か、生き方・意思決定寄りの中身で、読者が「今日から動ける」具体性があること。**体系だったノウハウ商品(「〇〇の完全マニュアル」)にはしない**。「どんな価値があるか」が書けなければ有料にしない
- 価格の目安：実用系1,842円前後・読み物系983円前後(`参考資料/note_monetization_reference.md`の相場)。根拠なく高額(5,000円以上)にしない
- 禁止：成果の数字や保証で購入を促す(「月○万」を約束の形で置く)。「本当は◯万円の価値」のような煽り。収益の画面のスクリーンショット
