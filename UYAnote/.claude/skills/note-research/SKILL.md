# 検索キーワード確認の基準(手順の正本は `1_企画部/社員.md` のリサーチAI)

- 確かめるのは「実在するか(Googleのサジェスト・note内検索)」「競合の切り口(解説型か体験型か)」「UYA.の差別化の余地(体験を語る側で書けるか)」の3つ
- 読者が「いまの困りごと」として打ち込む言葉か／本文で実際に答えられる言葉かで選ぶ。体験記と合わない語(おすすめ・ランキング等)は後回し
- 検索の数(月間の検索回数)は無料では取れない。推測で書かない
- noteの購入数は非公開。「何部売れた」は推測で書かない
- 取り方は `参考資料/note_research_snippets.md`
