# 作業の終わり(今回のやり取りを、次の提案に効かせる)

オーナーが作業の終わりを伝えたら、この手順を1回だけ行う(合図はフック `.claude/hooks/owari_signal.py` が拾って知らせる。知らせが無くても、終わりの合図なら行う)。
- 合図に続きの指示が付いているとき(「作業終わりにしたいけど、もう1本直して」など)は、先に続きの作業をして、そのあとでこの手順を行う
- 拾う範囲は、**この会話の中で起きたことだけ**。ファイルを広く読み直さない(開くのは、書き込む先の該当の節だけ)
- この手順は、オーナーの指示として行う(`0_社長室/全AI共通の決まり.md` の「ついでの改善はしない」の例外)

## 1. 今回のやり取りから拾う
- オーナーの直し(直す前→後)と、直した理由
- 実際に出した版(「Xに出しました」などで受けたもの)
- 直さずにそのまま通した投稿・記事の部分
- オーナーが言葉で伝えた意図(「今後は〜」「〜は嫌」など)
- 作業の流れの手間: 同じやり直しが2回以上起きた所／確認や待ちが多かった所／AIへの指示とファイルの決まりが食い違った所／今回の新しい決まりで、やる意味がなくなった工程

拾うものが何もなければ、「[社長室 → あなた] 今回、反映することはありません」と1行で返して終わる(コミットもしない)。

## 2. 振り分けて書き込む(確認を取らずに保存する)
すでに作業の途中で反映した分は、重ねて書かない。

| 拾ったもの | 書き込む先 |
|---|---|
| 言い回し・語尾・締め・読点などの直し(1回目) | X: `3_広報部/X投稿の型.md`、スレッズ: `3_広報部/スレッズ投稿の型.md` の「直した前後」の節のいちばん上に1組(足し方はその節の冒頭) |
| 同じ種類の直しが2回目(「直した前後」に同じ種類の組がある) | その型の決まりの該当の所を置き換えて、「直した前後」のその組は外す |
| 機械で数えられる直し(読点の数・使わない言葉・字数など)が2回目 | 型に書かずに `.claude/hooks/qa_post_x.py` に足す。足したら、`3_広報部/X投稿文/` と `3_広報部/スレッズ投稿文/` の直近の提案ファイル2本ずつにかけ、オーナーが通した文を誤って止めないことを確かめる |
| オーナーが「今後は〜」とはっきり決めたこと | 1回目でも、その話題の正のファイル(型・`社員.md`・`CLAUDE.md`)を置き換える |
| 事実の訂正・本人の本音 | `0_社長室/X投稿の本音メモ.md` に日付つきで足す(note記事のときは、事実の正 `0_社長室/UYA設定/personal_data.md` との食い違いだけ報告する。勝手に書き換えない) |
| note記事の直し | `0_社長室/学びの台帳.md`(運用は `CLAUDE.md`「学びの台帳の運用」)。`note-learn` スキルで済ませた分は重ねない |
| 作業の流れの改善 | 手順の正(`CLAUDE.md`・各部署の `社員.md`・`.claude/agents/`)の該当の所を置き換える。決まりは1か所にだけ書き、ほかには「正は〇〇」と場所だけ書く |

- 書き足すより置き換える。同じ話題の古い言い方は、新しい言い方に直す(これは「消す」に入れない)
- 1回きりの好みの直しは、決まりにしない(「直した前後」に残すだけ)
- 「直した前後」は、型ごとに5組まで。超えたら、いちばん古い組を外す(これも「消す」に入れない。報告に書く)

## 3. 消す候補を探す(ここだけ確認を取る)
手順2で書き込んだファイルと、今回の作業で使ったファイルの中だけを見る。
- 今回の決まりで要らなくなった、古い指示(まるごと要らなくなったもの)
- 2か所以上に同じことが書いてある所(正のファイル以外の方)
- 今回の改善で、やる意味がなくなった工程

候補は、まとめて1回で見せる。形は、番号・ファイル・消す文の全文・消す理由(1行)。
「[社長室 → あなた] 消す候補 N件。消してよい番号を教えてください(全部なら『全部』)」と聞いて止まる。OKをもらった番号だけ消す。候補が無ければ、聞かずに手順4へ進む。

## 4. 数を残す
`0_社長室/修正の記録.md` の「X・スレッズ」の表に、媒体ごとに1行足す(今回、投稿の提案をしたときだけ)。note記事の行は、これまでどおり `note-learn` のBで足す。

## 5. 保存して報告する
1. コミットする(メッセージは「UYA 作業の終わり: 反映の要点」)。クラウドの作業場で動いているときは、作業中のブランチへプッシュまで行う
2. 報告は1回、次の3点だけ:
```
[社長室 → あなた] 作業の終わりの反映
- 反映したこと: ファイルごとに1行(何を・なぜ)
- 消したこと: 番号と1行(無ければ「なし」)。外した見本の組もここに書く
- 次回に気にすること: 確度が中・低の反映、決まりにするか迷ったもの(無ければ「なし」)
```
