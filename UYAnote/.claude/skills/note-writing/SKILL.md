# 記事の書き方(UYA.の決まり)

このスキルは入口だけ。中身の正本は次のとおり。ここに無い「売れるnoteの型」(痛みを書いて煽る・参考書型など)は使わない。

- 構成・本文・有料記事の扱い・編集のチェック項目 → `2_商品開発部/社員.md`
- 立ち位置・禁止事項 → `0_社長室/UYA設定/project_uya_positioning.md`
- 文体・見た目の見本(1〜3・5〜7・10節) → `0_社長室/UYA設定/examples_essay.md`
- 事実・開示ルール → `0_社長室/UYA設定/personal_data.md`
- オーナーの直しの意図 → `0_社長室/学びの台帳.md`

要点: 当事者の記録／得を先に出して冒頭／捏造しない／「〜と思います」を使わない／結びは体験の結果／表・空欄を作らない／有料は目印の行「----- ここから有料 -----」を独立した段落で1本だけ
