# note有料記事の書き方リファレンス（全アカウント共通・仕組みの部分のみ）

オーナー提供資料（2026-09-27、「売れるnoteを運用するための書き方 第2版」）のうち、**トーンに関係ない客観的な仕組みの部分**を、全アカウント共通の参考資料として整理したもの。`参考資料/note_monetization_reference.md`（notekaigiの思考モデル）・`参考資料/note_terms_prohibited_conduct_reference.md`（禁止行為）とは別の、「書き方・作り方」専門の資料。

**採用しなかった部分**：この資料に含まれる「売れる型のテンプレート」（1記事1ゴール・A×C型などの構成の型、無料パート・有料パートの定型スケルトン）は、s4lvのような「ノウハウを体系立てて教える」アカウント向けの手法。UYA.のように「当事者としてその都度記録する」トーンのアカウントでは、そのまま型にはめず、`0_社長室/UYA設定/project_uya_positioning.md`の判断を優先する（2026-09-27にオーナーと精査済み）。

**信頼度について**：公式データ（noteの30万件分析・ヘルプ記事）は事実として扱ってよい。個人のX投稿を根拠にした数値（らっこ・平城寿・はるねずみ等）は自己申告の参考値であり、公式データと同列の「事実」としては扱わない。

## 1. 売れないときの切り分け（診断の考え方）

数字を見ずに本文を直すと、原因と無関係な改修になる。

- **A. 記事が開かれていない**：直すのはタイトル・見出し画像・SNSの投稿文・プロフィール・ハッシュタグ。本文を長くしても届かない
- **B. 開かれているが無料パートで離脱**：直すのは冒頭3行・対象の場面・ベネフィット・購入ライン直前の中身列挙
- **C. 無料パートは読了されるが買われない**：直すのは「有料で手に入る実行物」の具体性・価格と期待の一致・買う理由
- **D. 買われたが評価が低い／返金が出る**：直すのは有料パートの具体性・タイトルとの一致・誇大表現の有無

## 2. 公式が示している事実

- 無料エリアは購入判断の重要な情報源（購入されやすい要素：共感・問いかけ・変化の物語・ベネフィット）
- 実用ノウハウの平均価格1,842円・読み物983円（`note_monetization_reference.md`と同じ数値）。文字数と売上の相関はほぼゼロ
- 価格の目安：創作500円〜、ノウハウ1,000円〜、相談等3,000円〜。最低100円。上限は一般5万円・プレミアム/proは10万円
- **タイトルは15〜25字程度**。長いと一覧やXで省略されクリックされにくい。具体性と検索されうる語を入れる。記号で無理に目立たせるのは逆効果（公式ヘルプ）
- **見出し画像は推奨比率2:1**（編集部は1280×670pxを案内）。画像ありはPV・スキが数十パーセント違うとされる。内容と結びつく画像にする
- **ハッシュタグは5個前後が目安**。「日記」等の種類と「学び」等のテーマを組み合わせる。1記事最大10個、先頭の#を除き30字以内、ハイフン不可
- 有料ラインは1本のみ。購入ボタン付近は残り字数だけ表示。検索インデックスの対象は無料部分のみ
- 売上公開で購入を煽るのは規約違反（`note_terms_prohibited_conduct_reference.md`と同じ）

## 3. 運用の手順（公開後の直し方）

1. 読者の「つまずきポイント」を1つ決める
2. 無料記事でその1点を完結させる
3. 同じテーマの実行キットを有料にする
4. SNSでは記事の要約でなく、つまずきポイントの1場面を先に出してからURLを置く
5. **公開後72時間は、本文を増やすのではなく「タイトル／画像／冒頭3行／購入ライン直前」のどれか1つだけ変える**。変更前の文章と日時を残しておく
6. 売れたら中身を追記して値上げを検討。売れなければ、まず上記1の診断（A〜D）のどれに当たるかを見る

## 4. 公開前チェックリスト

- [ ] タイトルは15〜25字、見出し画像は2:1で中身と一致、ハッシュタグは3〜5個
- [ ] 無料パートの冒頭3行で場面が分かる。自己紹介から始まっていない
- [ ] 有料パートは「今日動ける」具体性がある。文字数を稼いでいない
- [ ] 規約：売上の誇示なし、「必ず稼げる」なし
- [ ] SNSまたは既存読者から開かれる導線がある
- [ ] 公開後に見る数字の順番：表示→開封（PV）→読了の手応え（スキ・コメント）→購入

## 5. 出典と信頼度

- **事実**：note公式の分析・ヘルプ記事（`note_monetization_reference.md`と重複する部分あり）
- **参考程度の反復知見**：個人のX投稿（らっこ・平城寿2,176本・はるねずみ100本等）。到達数や母数はまちまちで、公式データと重なる指摘だけを採用している
- **不採用**：ツール配布・実績誇張・フォロワー規模の自己申告だけを根拠にした必勝法
