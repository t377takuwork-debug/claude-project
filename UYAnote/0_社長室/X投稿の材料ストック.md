# X投稿の材料ストック(使ったら削除)

X投稿の材料として取っておく話題。**投稿に使ったら、その項目を削除する**(下の「削除の決まり」)。投稿文の調整が終わるまでの置き場。
X投稿AIは、材料を選ぶとき、このファイルも読む(あれば)。

## 削除の決まり
- 提案の「材料:」の行に、項目の名前(例: `ストック:Haiku5.5`)を書く
- 投稿を**予約した時点**で、親が、その項目を削除する(2026-10-10・オーナー許可。提案に入れただけでは、まだ消さない)
- 全項目が空になったら、このファイルごと削除する
- 古くなった項目は、使わずに削除してよい(ニュースの話題は、日がたつと古くなる。目安は2週間。確度: 中)
