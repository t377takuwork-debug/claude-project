# journals/themes.md — いまの考え(テーマごと・置き換え式)

音声ジャーナルでくり返し出てくる大きなテーマについて、オーナーの**いまの考え**をテーマごとに1つだけ置く。考えが変わったら書き足さずに置き換え、変わったことだけを1行残す(当時の発言は `journals/daily/` にそのまま残っている)。
s4lv・UYA.の投稿づくりと、X記事の取り込み(`.claude/commands/x-kiji.md`)の照らし合わせで、オーナーの考えの正として使う。

## 運用ルール

- 新しいジャーナルで、あるテーマの考えが出たら、そのテーマの「いまの考え」と比べる
  - 同じ考え: 書き足さない。「由来」に日付だけ足す
  - 深まった・細かくなった: 「いまの考え」を書き換える(1つの文章にまとめ直す)
  - 変わった: 「いまの考え」を置き換え、「変わったこと」に「日付: 前の考え → 今の考え」を1行残す
- 明確に新しい、くり返し出てくるテーマのときだけ、見出しを新しく立てる(1回きりの話題は `ideas.md`・`insights.md` 側で扱う)
- 「いまの考え」は、オーナーが話した言葉の範囲で書く。言っていない結論を足さない。はっきりしない所は、はっきりしないまま書く
- 「変わったこと」が5行を超えたら、古い行から消す(当時の発言は `daily/` で追える)

## 形

```
## テーマ名
- いまの考え: (2〜4文)
- 変わったこと: (日付: 前 → 今。無ければ「-」)
- 由来: journals/daily/YYYY-MM-DD.md, ...
```
